# Интерактивный курс: skills-decision-mockups

Нина помогает Льву организовать запись на занятия в мастерской. Вместе с ней вы подготовите
страницу, на которой можно сравнить варианты, узнать цену каждого и вернуть выбранный ответ в чат.
В курсе 12 разделов, шесть типов упражнений, итоговый тест и достижения. Язык — русский.

Курс посвящён [@dzhechkov/skills-decision-mockups](https://www.npmjs.com/package/@dzhechkov/skills-decision-mockups)
версии 0.1.9. Откройте `index.html` в браузере: файл работает без сети, прогресс хранится локально.

Установите пакет командой `dz install @dzhechkov/skills-decision-mockups`, затем вызовите
`/decision-mockups` в среде с поддержкой скиллов. Пакет содержит файлы скилла, исполняемого `bin` нет.
[Исходники скилла](https://github.com/djd1m/dz-harness/tree/main/packages/skills-decision-mockups).

В версии 0.1.9 экспорт и словари проверок русские, группы выбора плоские. Страница решений —
HTML-фрагмент для хоста, который добавляет оболочку документа. Варианты работают как кнопки
с `aria-pressed` и Enter/Space; перемещение стрелками как в полной радиогруппе не реализовано.
Скилл допускает объяснение без решений, но проверка наличия групп G6a отклоняет файл без вопросов.
Эти ограничения разобраны в курсе вместе с действиями, которые они требуют от автора.

Для редактирования используйте `course.json` — канонические данные курса в формате edu-site Step-0.
HTML создаётся скриптом `render-site.mjs` из
[@dzhechkov/skills-tutorial-factory](https://www.npmjs.com/package/@dzhechkov/skills-tutorial-factory).
После правки запускаются `headfirst-gate.mjs` и `verify-site.mjs`; второй выполняет упражнения
в DOM-адаптере. Копии JSON и HTML в `drafts/tutorials/skills-decision-mockups` синхронизируются
с каноническими файлами. Результаты редакторского ревью и проверок хранятся отдельно от уроков.
