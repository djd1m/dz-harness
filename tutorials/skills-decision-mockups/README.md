# Интерактивный курс: skills-decision-mockups

Практический курс по [@dzhechkov/skills-decision-mockups](https://www.npmjs.com/package/@dzhechkov/skills-decision-mockups)
на основе опубликованной версии 0.1.9: 12 разделов, шесть типов упражнений, итоговый тест и достижения. Русский язык.

Нина составляет страницу для вымышленной записи на занятия. Роли, даты, числа, макеты и оценки —
условия обучения, а не свидетельства о работающем продукте, реальных сроках или согласии адресата.
Настоящие [авторские исходники](https://github.com/djd1m/dz-harness/tree/main/packages/skills-decision-mockups)
сохранены; абсолютная невозможность сопоставления примеров не заявляется.

Откройте `index.html` в браузере: файл самодостаточен, работает без сети, прогресс хранится локально.
Установка пакета скилла: `dz install @dzhechkov/skills-decision-mockups`, затем `/decision-mockups`
в среде с поддержкой скиллов. Исполняемого `bin` у пакета нет.

`course.json` — исходные данные edu-site Step-0. HTML детерминированно создаётся
[@dzhechkov/skills-tutorial-factory](https://www.npmjs.com/package/@dzhechkov/skills-tutorial-factory).
Методические ссылки проверяются фабричным Head-First gate, а `verify-site.mjs` выполняет упражнения
в DOM-адаптере. Эти проверки не подтверждают педагогическую ценность, реальную отрисовку браузера,
семантическую правильность рекомендаций или точность оценок. Историческая оценка предыдущего курса
и прежние одобрения не перенесены; текущее независимое ревью фиксируется отдельно.

Ограничения 0.1.9: русский экспорт и gate-словарь; HTML-фрагмент с оболочкой от хоста; плоские группы;
кнопки с `aria-pressed` без полной радиосемантики со стрелками. Скилл допускает объяснение без решений,
но неизменённый `check_page.py` отвергает ноль групп по G6a. Часть сообщений gate — advisory;
его структурный результат не доказывает полезность альтернатив и достоверность цен.
