# Product demo sites

Здесь публикуются готовые наборы демонстраций: `tutorials/demo/<set>/index.html`, страницы отдельных
роликов и их локальные файлы в `video/`. Каталог обучающих курсов намеренно не считает эту директорию
курсом.

Новый набор попадает сюда только через `demo-site-publisher`: после офлайн smoke-проверки, проверки
размера и явной санкции владельца. Публичный клон получает HTML и видео; исходные сценарии, кадры и
сырые записи остаются вне этого дерева. Успех публикации подтверждается совпадением байтов страницы и
размеров MP4 на GitHub Pages.
