**[Открыть онлайн](https://djd1m.github.io/dz-harness/tutorials/feature-adr/)** — или скачайте
`index.html` и откройте в браузере (файл самодостаточен, прогресс хранится локально).

структура проверена детерминированным гейтом (14 свойств), сайт — поведенческой верификацией
(37 проверок), текст прошёл кросс-модельное ревью и литературную правку.
