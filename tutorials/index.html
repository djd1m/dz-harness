Обучалки по инструментам

Интерактивные курсы по пакетам harness-hub — по курсу на инструмент. Открываются в браузере, ничего ставить не нужно; прогресс хранится локально у вас.

КурсКакую задачу решаетПакет
book-digitizer Превращает инженерную книгу (PDF) в устанавливаемый пакет навыков и базу знаний: ассистент начинает проектировать по методикам книги, а не по общим приёмам. @dzhechkov/skills-book-digitizer
cloudru-hub Подключает MCP-движок Cloud.ru к агенту так, чтобы платные шаги требовали явного разрешения, а не срабатывали молча. @dzhechkov/cloudru-hub
design-thinking Помогает проверить сырую продуктовую идею на людях, отделить подтверждённые потребности от догадок и выбрать решение для дальнейшей разработки. @dzhechkov/design-thinking
evidence-wiki Не даёт исследованию превратиться в набор цифр без источников: каждое утверждение получает проверяемую ссылку. @dzhechkov/evidence-wiki
feature-adr Помогает довести одну фичу от согласованных требований и зафиксированных архитектурных решений (ADR) до проверенного кода — без проектирования всего продукта с нуля. @dzhechkov/skills-feature-adr
harness-cli Помогает устанавливать, обновлять и согласованно поддерживать навыки AI-ассистентов в разных средах разработки. @dzhechkov/harness-cli
health-advisor Помогает подготовиться к разговору с врачом: понять результаты анализов, учесть условия их сдачи и проверить сочетания лекарств; данные остаются на компьютере пользователя. @dzhechkov/health-advisor
idea2prd Помогает превратить проблему или сырую идею в согласованный комплект требований и решений, который можно передать кодирующему ассистенту. @dzhechkov/skills-idea2prd
keysarium Помогает понять, где ИИ принесёт пользу продукту, собрать аргументы и подготовить защиту выбранного сценария перед заинтересованными сторонами. @dzhechkov/keysarium
loop-designer Помогает спроектировать воспроизводимую многошаговую работу AI-агентов и заранее определить, как проверять результат каждого запуска. @dzhechkov/loop-designer-plugin
news Помогает регулярно следить за новостями по теме: получать дайджест со ссылками на источники и в следующих выпусках видеть только новое. @dzhechkov/skills-news
p-replicator Помогает развернуть новый проект целиком: подготовить среду для AI-разработки и превратить исходную идею в приложение, готовое к запуску. @dzhechkov/p-replicator
presentation-storyteller Помогает превратить тему в презентацию для защиты: выстроить аргументацию, подтвердить факты источниками и подготовить речь к слайдам. @dzhechkov/skills-presentation-storyteller
scout Ищет по одиннадцати источникам новые навыки и инструменты для харнеса агента вместо ручного просмотра GitHub. @dzhechkov/scout
skills-bto Проверяет навыки и команды агента измерением вместо чтения: сборка, замер, тест, оптимизация с честным вердиктом «недостаточно данных». @dzhechkov/skills-bto
skills-devops Переводит дежурные задачи инженера — ревью, аудит, миграции, инциденты, деплой — в протоколы, которые агент выполняет одинаково. @dzhechkov/skills-devops
skills-mcp Даёт агенту рабочие инструкции к MCP-серверам — поиск, почта, календарь, таблицы, git — вместо угадывания их протокола. @dzhechkov/skills-mcp
skills-qe Заставляет агента предъявлять свежее свидетельство качества до слова «готово», а не отчитываться о зелёных тестах на слово. @dzhechkov/skills-qe
skills-reasoning Меняет не то, что агент знает, а как он думает: проговорённые допущения, хирургические правки, красный-зелёный-рефакторинг. @dzhechkov/skills-reasoning
trip-planner Складывает поездку в один автономный мобильный HTML-файл: дни, карты, погода, проверенные контакты мест — вместо вороха вкладок и заметок. @dzhechkov/trip-planner
tutorial-factory Делает из одного пакета интерактивный курс в стиле Head First — сайт, который проверяется прохождением; учит людей пакету, тогда как book-digitizer учит ассистента книге. @dzhechkov/skills-tutorial-factory
