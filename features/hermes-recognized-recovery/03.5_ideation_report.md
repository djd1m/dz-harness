# Ideation report: synthetic recognized recovery verifier

Статус: design clarification 2026-11-10, до K2/design review и runtime implementation. Основание — [независимый upstream challenge](../hermes-night-acceptance/recognized-recovery-challenge.md); это не новая QE приёмка, историческое согласие или разрешение migration.

| Challenge | Решение текущего read-only этапа | Что остаётся открытым |
| --- | --- | --- |
| B1, trust root | Trusted external descriptor с `schema/snapshot_id/inventory_sha256/key_sha256/expected_owner/expected_runtime`; original 32-byte key отдельным private файлом вне export. Inventory digest связывает exact bytes и snapshot ID. Wrong key/MAC — один integrity refusal, lost key — отдельный refusal. | Provenance descriptor/key, историческая полнота backup и human authenticity не доказаны. |
| B2, receipt states | Только `saved_unverified` и `artifact_observed=true`; one-to-one core/receipt, exact owner/runtime/workspace/sidecar/tuple/source/engine. Все иные state/flag, orphan и ambiguity отказывают всему batch. TTL не является новым согласием. | Новая operator attestation и право на save требуют отдельной схемы. |
| B3, freeze/export | Заранее созданный offline synthetic export без writers, ограниченный profile: manifest/raw, core operations, completed receipts. Key, lock, pending, staging, draft и LOG явно исключены; extra object отказывает. | Нет процедуры quiesce live writers или единого snapshot epoch для production. |
| B4, confinement | Private owned roots и ancestors, fd-relative no-follow чтение, exact closed directory/file membership, no overlap/aliases, single-link regular files, modes и ресурсы ограничены. Только sanitized `executable:false` report, без target/mapping. | Same-UID hostile actor вне модели; target identity/ownership и replay относятся к будущему writer. |

B5 (durable state machine, seal, fsync, crash/replay) не решается read-only verifier. Его нельзя считать pre-approved migration plan. Вариант in-place rebind отклонён: меняет прежнее свидетельство. Разрешённый текущий результат — отчёт о согласованности входа, не операция восстановления.

Проверка дизайна должна отдельно подтвердить actual `JSON.stringify` core metadata/tuple и Python adapter `encode` HMAC, логический `manifest.path` против физического `stored_at`, точную внешнюю owner/runtime binding, ограниченность JSON/output и semantic adversarial fixtures после переиздания inventory/HMAC. K1 name-check остаётся **NOT ESTABLISHED** для Python: manual `rg` notfound не заменяет scanner.
