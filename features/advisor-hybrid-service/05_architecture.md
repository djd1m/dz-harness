# Architecture
Browser → existing Caddy → advisor HTTP/admission → query embedding (provider) → private search HTTP → reusable Lance snapshot → IDs → host-owned catalog records → cheap selector → fixed reviewed renderer.

Offline builder: verified catalog → document embeddings → reusable snapshot module → new immutable generation directory. Operator picks that directory for next restart; no background mutating current index. Search has no API key; advisor has no Lance native dependency. Reuse existing source checks, selector, request ledger and site admission/HTTP (inject answer callback). Public UI and generic static route stay unchanged.

Settled review clarifications: advisor wrapper opens both existing ledger files after explicit existence checks. Site admission reserves once; callback reserves canonical model ledger once before embedding. Preview createPreview remains unchanged and never receives this metered callback, preventing double reservation. Missing state fails closed; mounts are writable parent directories with mapped nonroot UID, not individual files. Timeout/client disconnect retains active admission until upstream settles. Stale locks require stopped-owner verification and lock-only recovery; counts never reset. Search request carries expected revision/model/dimension/lexicalizer; mismatch is an integrity error, not an availability fallback. Health endpoints are unpaid. Each outbound stage has a deadline (embedding5s, search2s, selector60s); Caddy75s, stopGrace90s.
