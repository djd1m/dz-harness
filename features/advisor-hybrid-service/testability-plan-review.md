# Testability plan review

Verdict: implementable with the following explicit checks and plan corrections. Review only; no implementation or paid calls performed.

## Concrete plan inconsistencies / omissions

1. **Task 2 code target mismatch:** generic selector instructions currently live in `integrations/skill-advisor-catalog/search.mjs` (`pickerInstructions`), which is absent from EXPECTED_CODE_TARGETS. Add it explicitly; do not introduce a parallel selection contract in the adapter. Existing `pickerInput` already includes steps/evidence, so demonstrate the actual missing excerpt before changing data.
2. **Task 4 deliverables missing from target list:** add the site repository `scripts/lib/advisor-http.mjs`, its API tests, container entrypoint and `deploy/advisor-containers/*`, plus reusable package manifest/lock/export files. Name which repository owns each and the two pinned revisions used to assemble images.
3. **Timeout contract unresolved:** existing HTTP handler allows 65 seconds, selector allows 60 seconds, and embedding/search add latency. Allocate one end-to-end deadline (with phase budgets) or state a deliberate HTTP deadline change. An injected callback must not release admission while model work continues after a response timeout; test cancellation and single-active behavior.
4. **Read-only vs persistent state:** admission atomically writes a sibling temporary file and creates a sibling `.lock`; a writable state-file mount alone will fail. Declare the narrow writable private state-directory volume and test atomic rename/fsync and lock creation there. No startup initialization. SIGKILL leaves the existing exclusive lock: preserve fail-closed behavior or explicitly document manual recovery, never silently reset counters.

## Falsifying integration checks

- **Portable package:** `npm pack`, install the tarball into a fresh directory outside either repository, import only public exports, build/search an unrelated corpus (e.g. museum object descriptions) using consumer-supplied lexicalizer/ID and deterministic vectors. Reopen in a separate process and query through packaged HTTP. Remove access to DZ paths; no provider key. Assert known exact top-five IDs/order using an independent RRF calculation, including ties and fewer-than-five matches. Keep the real advisor corpus disk roundtrip separately. This tests portability without extra paid embeddings.
- **Snapshot integrity:** mutate document text, IDs, vector values (same dimension), model, revision and lexicalizer ID independently; stale/corrupt snapshots must fail before search. Reject duplicate IDs, nonfinite/wrong-size vectors and unsupported manifests. Interrupt staging build and race two builders against the same destination: previously published generation stays byte-identical/readable, partial generations cannot open, no replacement of an existing immutable generation.
- **Adapter trust:** real Lance service returns IDs; only host-verified records reach the existing selector/renderer. Inject unknown/duplicate IDs, stale revision, malformed/oversized responses and unavailable/timeouting search. Assert explicit lexical fallback, one attempt, no stale vectors, no response-provided text/URL/course mapping materialized, and logs contain neither query nor credentials. Preserve existing selector rejection of unreturned IDs and at-most-two recommendations.
- **Real Docker topology:** start the candidate images with a test-only populated state volume and nonsecret canary credential. Requests originate from a test client on edge; an outsider network cannot reach search. Inspect no published ports, no Docker socket/source mounts, nonroot UID, read-only root/index, dropped caps and applied resource limits. Search cannot read the credential or reach provider egress; image layers/config/logs contain no canary key. Advisor image has no Lance addon. Verify health probes under strict Host checks (current API-only handler requires `aicoding.space`, and all GET API paths currently 404), graceful SIGTERM, and cleanup.
- **Admission continuity:** seed existing-format state at 29 total and at 9 daily; one accepted call persists the next value, the next is rejected, including after container restart. Failed provider/search calls still consume the reservation according to existing policy. Exercise five-second cooldown, overlapping requests, state corruption/missing state, second-process lock and interrupted request shutdown. Invalid origin/Host/body must consume no quota and trigger no provider call. Preserve 24,000-byte body and 6,000-character query bounds or explicitly justify changes. Use isolated fixture ledgers only, including any separate model-cost ledger.
- **No publication:** inspect publication flag remains false and production Caddy/Docker diff is empty; separately exercise unchanged static route behavior in the existing site HTTP tests. Candidate edge routing can be tested in an isolated harness; no live Caddy mutation required.
