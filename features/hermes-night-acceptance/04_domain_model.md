# Границы предметных областей ночной приёмки

| Область | Объект и авторитет | Допустимое изменение ночью |
| --- | --- | --- |
| Источники | manifest entry_id, SHA-256 и исходные байты | Только новая синтетическая карта; рабочая карта read-only для тестов |
| Распознанный текст | immutable operation, source binding, engine/version, точные байты текста | Экспериментальный core; not_established всегда, отдельное пользовательское подтверждение через gateway |
| Подтверждение | receipt, trusted gateway identity, workspace/runtime identity | Изолированный adapter, LLM только prepare; confirm отдельная команда |
| Индекс | Производная копия для поиска, не источник клинической истины | Только изолированный индекс; save не повторяется при index failure |
| Резервное копирование | Offsite snapshot с файлами и metadata | Восстановление в отдельный root0700 каталог; не запускать gateway из restore |
| OAuth | Grant принадлежит конкретному штатному клиенту; offline owner — только модель | Искусственные токены в лаборатории; реальный refresh не вызывается |

Integrity verified означает совпадение байтов, а не клиническую проверку.
Согласие сохранить машинный текст не является human verification.
Состояние save не выводится из состояния индекса. Наличие локального файла не
доказывает возможность восстановления из S3. HTTP200 access-token не доказывает
безопасность следующего refresh.

Legacy writers не разделяют новый lock. Наблюдаемые source changes приводят к
отказу, но ABA и изменение после последней проверки не исключены. Отдельная
операция в отдельном процессе не является общей транзакцией всех хранилищ.
