# Приёмка существующего механизма индексации

Scope S: один автономный интеграционный сценарий в закреплённом health runtime,
без production volumes и сети. Только синтетический технический текст.
Это исследование поведения существующего third-brain, не готовый gateway index tool.

- FR-1: успешный ingest должен находить известный исходник с проверенным SHA, не только exit 0.
- FR-2: повторная индексация неизменного документа не увеличивает количество memory_records.
- FR-3: после удаления одного chunk в тестовой SQLite повторный ingest восстанавливает ожидаемый набор; если контракт не выполнен, фиксируется фактический отказ.
- FR-4: неизменность исходного текста и human-verification markers; stale source должен вызывать отказ search.
- FR-5: скрытая namespace recognized/.machine-unverified должна проверяться отдельно; текущий запрет не обходить в сценарии. Записать limitation, не объявлять search поддержанным.

Backlog: не заведено — shared dz store guard unreadable; восстановление store не входит в работу.
