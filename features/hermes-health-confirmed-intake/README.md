# Подтверждаемое добавление медицинских оригиналов

Статус: проект следующей итерации и проверка контрактов ядра, **не реализованный инструмент записи**. Рабочая версия 0.2 остаётся без изменения; пользователь подтвердил полный PDF-предпросмотр с точным дубликатом.

- [Требования](01_requirements.md)
- [ADR: подтверждение и отказоустойчивость](03_adr/001-human-confirmed-intake.md)
- [HLD/LLD и последовательность](05_architecture.md)
- [План реализации и критерии выпуска](06_implementation_plan.md)
- [Измеренные ограничения](08_qe_report.md)

Результат разработки должен сохранять оригиналы и их происхождение. OCR, клиническое подтверждение, обновление профиля, семантическое индексирование и публикация Git — отдельные шаги. Пока этого результата нет, не предлагать пользователю несуществующую команду добавления.
