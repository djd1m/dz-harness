# Требования

- FR-1: Hermes регистрирует health_search, health_source_get, health_validate и мастер-навык.
- FR-2: поиск через CLI JSON возвращает проверяемые источники и явную ошибку при сбое, а не ложный пустой результат.
- FR-3: чтение ограничено операторским workspace и каталогами документов; секреты, скрытые пути и выход через symlink запрещены.
- FR-4: проверка хешей и размеров manifest не меняет карту; неподтверждённое не становится подтверждённым.
- NFR-1: ограниченные размер вывода и время subprocess, argv без shell; ошибки не раскрывают данные stderr.
- NFR-2: публичные fixtures синтетические; никаких токенов, адресов пациента или медицинской карты.
- AC-1: unit tests и реальный Hermes plugin doctor/validate проходят в отдельном контейнере.
- AC-2: инструкция установки, совместимость и откат; PR в djd1m/dz-harness без изменения опубликованных пакетов.
