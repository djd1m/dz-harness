# Следующая итерация: предпросмотр приёма документа

Статус: предпросмотр реализован в 0.2 по ADR-002; операции записи остаются проектом.

## Уточнение контракта ядра

`health-advisor intake-archive --dry-run` проверяет параметры и строит план до распаковки. Успех не означает проверку содержимого ZIP, лимитов распаковки или внутренних документов. Называть такой ответ «архив проверен» нельзя.

## Предлагаемое решение

- Отдельный `health_intake_preview` принимает basename сохранённого вложения, а не произвольный путь, URL или команду. Оператор задаёт отдельный inbox; сопоставление basename с вложением требует проверенного адаптера Mattermost.
- Ограниченное чтение без symlink, снимок байтов, SHA-256. PDF проверяется как документ и упаковывается в технический ZIP для имеющегося intake-ядра; произвольные архивы — отдельный явно поддерживаемый формат.
- Настоящий intake CLI выполняется только в приватном временном workspace без сети и credentials. Ограничения распаковки ядра, время, размер и число файлов обязательны. Вывод — список предполагаемых источников с хешами, фактические отказы, признаки точных дубликатов по текущему manifest. Это не OCR и не клиническая верификация.
- Preview не является разрешением записи. Последующая операция commit должна заново сверять байты и версию manifest, сериализоваться общим lock с другими писателями и сохранять idempotency receipt. Не создавать отдельный lock, который существующий CLI не учитывает.
- Предпросмотр не обещает воспроизведение entry_id/результатов после изменения входа. Частично успешные этапы сохранения и индексирования различать явно.

## Приёмка перед операциями записи

Синтетический PDF с русским именем; ZIP traversal/symlink/лимиты/повреждение; повтор одного вложения; смена байтов после preview; два одновременных запроса; остановка посередине операции; восстановление и возврат HTML/PDF через тестовый Mattermost. Для CLI без нужного JSON-контракта сначала изменение общего ядра и совместимость Claude, затем native adapter. Публичное зеркало npm не заменяет source/release pipeline ядра.
