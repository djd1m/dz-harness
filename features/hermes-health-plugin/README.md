# Нативный health-плагин Hermes: чтение и предпросмотр

Цель: три инструмента чтения и предпросмотр PDF/ZIP поверх общего health-advisor CLI, без изменения совместимости Claude и без медицинских данных в публичном репозитории.

- Решение: [ADR-001](03_adr/001-isolate-read-tools.md).
- Реализация и воспроизводимая проверка: [инструкция](../../integrations/hermes-health/README.md).
- Результаты и ограничения: [QE](08_qe_report.md).

Версия 0.2 добавляет предпросмотр через настоящее intake-ядро во временном workspace и проверку точных дублей. Запись карты остаётся вне плагина. Дальше: пользовательская проверка PDF через Mattermost, затем отдельно проектируем подтверждаемую запись через общее ядро.
