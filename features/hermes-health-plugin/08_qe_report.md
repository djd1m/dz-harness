Статус: PR открыт; после исходной проверки выполнен ограниченный рабочий запуск, см. дополнение ниже.

## Подтверждённые результаты

- 15 unittest-проверок прошли на Python 3.12: регистрация, чтение, хеши, запрет traversal/symlink, ограничения размера и subprocess, отсутствие индекса, нестабильный снимок, чрезмерная вложенность JSON, запрет SQLite view вместо таблицы.
- Интеграционный тест прошёл в отдельном контейнере без сети, credentials и производственных томов: Hermes 0.22.2, Node 22.23.4, health-advisor 1.10.8, harness-cli 0.7.5, better-sqlite3 11.10.0. Использован синтетический технический документ.
- Настоящий CLI создал индекс и нашёл известный источник; SHA-256 совпал. После изменения исходника поиск отказал. Подмена тела индексной записи при сохранении валидного заголовка не попала в ответ: цитируется текущий исходный файл.
- До и после поиска сравнивались хеши и состав файлов рабочей копии: изменений нет. Нативная SQLite-зависимость проверяется отдельно; отсутствие runtime не превращается в пустой успешный результат.
- Настоящие Hermes plugins doctor и plugins validate прошли, зарегистрированы три инструмента.

## Независимое ревью и исправления

1. Непроверенный текст индексной записи заменён отрывком из проверенного текущего документа.
2. RecursionError чрезмерно вложенного JSON возвращается как обезличенная ошибка; добавлен регрессионный тест.
3. memory_records обязан быть таблицей; SQLite COUNT ограничен progress deadline. Добавлен тест рекурсивного view.
4. Первый интеграционный прогон выявил создание SHM при чтении live SQLite. Теперь DB+WAL читаются дважды, проверяются на стабильность, а Backup API выполняется только над приватной копией.

## Ограничения

Это read-only версия: нет приёма PDF, записи карты, клинического подтверждения и отправки вложений. Их проверка в миграции не является проверкой данного плагина. Поиск охватывает third-brain, а не всю карту; отсутствие результата не означает отсутствие документа. validate проверяет только перечисленные manifest файлы. При активной записи индекса возможен безопасный отказ с повтором. Полная конкурентная нагрузка WAL и тест уничтожения внуков процесса пока не покрыты отдельными сценариями. Рабочее включение требует отдельной проверки конфигурации и новой сессии Hermes.
