# ADR-002: Предпросмотр через настоящее intake-ядро в временной карте

## Status
Принято для тестовой версии 0.2; рабочая версия 0.1 продолжает обслуживать чтение.

## Context
Штатный intake --dry-run не распаковывает ZIP. Hermes Mattermost сохраняет документы с уникальным basename doc_<uuid>_<filename> в локальный кэш. В доступном runtime нет отдельного PDF-парсера.

## Decision Drivers
Не менять рабочую карту, сохранить общее ядро и не обещать несуществующую OCR/клиническую проверку; bounded resources и отсутствие секретов в subprocess.

## Options
1. Считать --dry-run полноценной проверкой: отвергнуто, содержимое не проверяется.
2. Написать Python ZIP intake заново: отвергнуто, дублирование защит ядра.
3. Использовать настоящее ядро на приватном временном workspace: выбрано.

## Decision
Новый health_intake_preview принимает только basename файла в HEALTH_INBOX и необязательный ожидаемый SHA-256. No-follow чтение до 16 MiB фиксирует байты. PDF проверяется только по заголовку и EOF, без интерпретации; помещается в несжатый технический ZIP. ZIP передаётся ядру без Python-распаковки. Ядро работает с локальным --file и временными workspace/HOME, без credentials, не выполняет сетевой transport. Это не OS sandbox: отсутствие сетевых запросов проверяется в тесте с --network none; закреплённому runtime доверяем.

Лимиты ядра: 100 записей, 16 MiB на файл, 64 MiB на распаковку, 20 MiB входного ZIP; subprocess 25 секунд и 2 MiB вывода. Результат читается из созданного временного manifest и проверяется по реальным байтам. Дубликат — совпадение SHA-256 и размера с manifest рабочей карты с повторной проверкой исходника. Drift даёт отказ, а не ложный verified duplicate. Хеш manifest сверяется до/после. Preview не разрешает commit и не гарантирует актуальность после возврата.

## Consequences
Содержимое временно занимает диск; оно удаляется в finally без обещания secure erase. Inbox доверенный операторский каталог внутри однопользовательского медицинского профиля: basename не является пользовательской авторизацией; общий multi-tenant inbox запрещён. Ошибка ядра обезличена, расширенная классификация ошибок будущая работа. PDF внутри ZIP не получает полную проверку структуры. Нет записи, OCR, клинической верификации или автоматической публикации.

## Confirmation
Синтетические PDF/ZIP, malformed и traversal ZIP, точный дубликат и drift, hash mismatch, symlink и traversal имени, no-live-writes, повтор и параллельный preview; настоящий Hermes doctor/validate в тестовом контейнере. Реальный upload через Mattermost — отдельная проверка перед включением 0.2.

Тесты: integrations/hermes-health/tests/test_intake_preview.py; integrations/hermes-health/tests/test_health_plugin.py.
