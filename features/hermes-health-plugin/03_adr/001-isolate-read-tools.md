# ADR-001: Изолировать инструменты чтения поверх существующего CLI

## Status
Принято для первой итерации. Пересмотреть при появлении read-only API ядра.

## Context
Hermes поддерживает register(ctx); adapter-hermes переносит навыки, но не предоставляет инструменты.
Текущий dz recall может открывать SQLite для записи служебных данных и скрывать ошибки native binding.
Публичное дерево packages является зеркалом npm; медицинские данные не относятся к исходникам плагина.

## Decision Drivers
Совместимость с Claude и CLI, отсутствие записи в карту, проверяемые источники, изоляция секретов.

## Options
1. Переписать полнотекстовый поиск на Python: проще процесс, но дублирование семантики ядра.
2. Прямой CLI на рабочей карте: повторное использование, но служебная запись SQLite и неявный fallback.
3. CLI на временном согласованном SQLite snapshot: повторное использование с изоляцией записи.

## Decision
Выбран вариант 3. Python дважды читает DB+WAL без symlink и требует побайтной стабильности пары.
Backup API выполняется только на этой приватной копии; SHM рабочей карты не создаётся.
Node, health-advisor и dz закреплены операторской конфигурацией; окружение дочерних процессов очищено.
Проверка native binding и ненулевого исходного индекса precedes search. Сам CLI получает только argv.
Результаты проверяются по SHA-256 текущих документов; при расхождении текст не выдаётся как актуальный.
Чтение источников и проверка manifest ограничены путями карты, статус проверки человеком не выводится из хеша.

## Consequences
Копирование индекса на каждый запрос требует временного места и времени; лимит размера явный.
Векторный поиск, intake и подтверждение клинических данных остаются вне версии 0.1.
Код интеграции находится вне packages/ и не является npm-релизом.

## Confirmation
- integrations/hermes-health/tests/test_health_plugin.py: неизменность workspace, неизвестные статусы, symlink/path confinement, устаревший индекс, недоступный runtime, timeout и лимиты.
- integrations/hermes-health/tests/integration_check.py: загрузка реальным Hermes и CLI на синтетическом индексе.
