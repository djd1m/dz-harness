DZ Harness

Harness CLI связывает задачу, контракт, реализацию агентом и независимые проверки.

Замечания возвращают работу к реализации. Принятые проверки ведут к результату с проверяемыми свидетельствами.

Начните с окружения

Установите CLI, откройте справку и проверьте готовность инструментов.

npm install -g @dzhechkov/harness-cli
dz --help
dz doctor
Руководство Harness CLI →
  • Контракт до реализации
  • Проверка независима от исполнителя
  • Результат содержит проверяемое evidence
