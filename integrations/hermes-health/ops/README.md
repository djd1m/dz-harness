# Резервное копирование установленного медицинского профиля

`backup-health.sh` — снимок рабочего скрипта ent-hub, а не универсальный
установщик. Он требует существующих restic, закрытого local.env и центрального
backup.sh. Перед использованием на другом хосте адаптировать пути и перечень
закреплённых пакетов. Секреты в скрипт не входят.

Скрипт кратко останавливает только медицинский контейнер, сохраняет карту,
архивы, Hermes home (включая intake-state и HMAC key), releases и конфигурацию.
При завершении/ошибке локального backup пытается запустить контейнер обратно.
Затем выполняет существующую центральную синхронизацию.

Наличие файлов в локальном snapshot проверяется отдельно; успешный локальный
backup не означает успешную доставку в S3. Восстановление сначала в отдельный
каталог. Локальный Docker base image скрипт не архивирует.
