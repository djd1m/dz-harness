# План изолированного эксперимента

1. Проверить локальные правила и доступность движка; закрепить версию в отдельном окружении.
2. Передавать парсеру только ограниченный снимок оригинала после сверки SHA-256. Читать файл без записи; возвращать JSON с entry_id, хешем, версией, страницами и статусом «не проверено человеком».
3. Выполнять разбор в дочернем процессе с лимитами памяти, CPU, времени, страниц и вывода. Отличать шифрование, повреждение, отсутствие текста и движка.
4. Проверить синтетические PDF, русский текст, неизменность оригинала, лимиты и экранирование HTML. Не подключать инструмент, OCR, индексацию или медицинские данные.

Рабочая область — только experiments/pdf-text. Это исследовательский прототип, не обновление production. Ограниченный процесс сам по себе не является ОС-песочницей.
