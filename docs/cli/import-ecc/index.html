dz import-ecc

dz import-ecc imports skill definitions from ECC (github.com/affaan-m/ECC) — a curated set of AI coding skills. DZ Harness Hub also ships an ECC-derived pack, canonicalized into the agentskills.io SKILL.md format. This command fetches SKILL.md files from the ECC repo (or a local clone), maps their frontmatter, deduplicates against your existing skills, and writes the result to an output directory.

Basic Usage

Section titled “Basic Usage”

By default, imported skills are written to ./imported-ecc-skills/. Install them into a target with dz init --target claude-code --skills-dir ./imported-ecc-skills.

What ECC Is

Section titled “What ECC Is”

ECC is the GitHub repository affaan-m/ECC, a curated collection of AI agent skills. Each skill is a SKILL.md file with structured frontmatter. DZ Harness Hub re-ships selected skills as the skills-ecc pack.

The agentshield-scan skill (sourced from ECC) wraps npx ecc-agentshield scan, which runs 170 rules across 10 security categories.

Frontmatter Mapping

Section titled “Frontmatter Mapping”

ECC skills use their own frontmatter schema. dz import-ecc maps the fields it reads into agentskills.io format. The importer parses the name and description from the ECC frontmatter and synthesizes the rest:

Source agentskills.io Field Notes
name name Parsed from ECC frontmatter
description description Parsed from ECC frontmatter (multi-line collapsed)
(synthesized) trust_tier: 0 All ECC imports are hardcoded to tier 0
(synthesized) trust_tier_label "Community (imported from ECC)"
(synthesized) source https://github.com/affaan-m/ECC/tree/main/skills/<name>

Imported skills always receive trust_tier: 0 until you manually promote them. This signals that the skill has not been locally reviewed for your project’s security context.

Deduplication

Section titled “Deduplication”

Before importing, dz import-ecc checks your existing .claude/skills/ directory. If a skill with the same ID already exists:

  • Without --force: the existing skill is skipped (counted as a duplicate)
  • With --force: the skill is re-imported and overwritten

Options

Section titled “Options”
Flag Description
--local-path <dir> Use a local ECC clone instead of fetching from GitHub
--select <ids> Comma-separated list of skill IDs to import
--limit <n> Maximum number of skills to import (default: all)
--output <dir> Output directory for imported skills (default: ./imported-ecc-skills)
--force Overwrite existing skills with the same ID
