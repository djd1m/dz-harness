dz scout

dz scout scans 9 sources in parallel for new AI agent skills, MCP servers, and community skill packages. It generates an intelligence report with gap analysis and integration recommendations. Use --deep for SKILL.md analysis, --report to print the report, --diff to compare against the last scan, and --output to save the report.

The 9 Sources

Section titled “The 9 Sources”

dz scout queries these sources in parallel:

# Source What It Scans
1 GitHub agent-skills, claude-code, mcp-server topics
2 npm Registry Packages with agent-skills, claude-skill, mcp-server keywords
3 Hacker News HN Algolia posts mentioning AI skills, MCP, agent workflows
4 MCP Registry Official MCP server registry
5 Glama Glama MCP server directory
6 OSSInsight Trending repositories by star velocity
7 Smithery Smithery MCP marketplace
8 Semantic Scholar Academic papers with citation counts and impact metrics
9 arXiv Research papers: multi-agent systems, tool use, skill learning

Scout compares discovered packages against the 31 DZ Harness Hub packages to find skills we don’t yet have.

Deep Mode (--deep)

Section titled “Deep Mode (--deep)”

In deep mode, dz scout fetches the SKILL.md (or equivalent) from each GitHub result and runs additional analysis:

  • SKILL.md parsing — extracts title, description, version, tags, trust_tier
  • Gap scoring — compares against existing skills to measure novelty
  • Integration recommendation — one of: integrate, monitor, skip

Relevance is scored by format (40%) + stars (30%) + recency (20%) + novelty (10%). Recommendations: integrate (score ≥ 70), monitor (40–69 with ≥ 50 stars), or skip.

Options

Section titled “Options”
Flag Description
--topics <list> Comma-separated topics to focus the scan
--since <date> Only include repos/packages updated since this date (e.g. 2026-05-01)
--deep Enable SKILL.md parsing and gap analysis
--output <file> Save report to a markdown file
--report Print the intelligence report
--diff Compare against the last saved scan
