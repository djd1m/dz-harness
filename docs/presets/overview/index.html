Presets Overview

Presets are curated bundles that install a set of skills together. Pick the one that matches your workflow, or compose your own. Run dz stats to inspect the current installed inventory.

Available Presets

Section titled “Available Presets”
Preset Focus
devops Code review, security audit, testing, CI/CD, debugging, API design, infrastructure, ITSM/ITIL
mcp MCP integrations including search, messaging, and knowledge tools
web3 Blockchain and decentralized application workflows
qe-engineer Quality engineering, testing, coverage, and resilience
meta Cross-cutting research and orchestration skills
keysarium Research and presentation workflows
p-replicator AI-assisted product development
feature-adr ADR-driven feature development
health Medical AI workflows
academic Academic evaluation
news News and monitoring
bto Build-Benchmark-Test-Optimize
reasoning Reasoning and investigation
pm Product management

The table describes each preset’s purpose. To see the exact members in your installed version, run dz stats or inspect the published package files.
