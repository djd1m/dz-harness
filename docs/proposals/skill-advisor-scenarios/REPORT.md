# Пилот базы сценариев для skill-advisor

Дата: 2026-11-09. Статус: исследовательский прототип в draft PR; не подключён к сайту и не выпущен в npm.

## Что сделано

24 сценария для 12 пакетов: [таблица](SCENARIOS.md), [полные записи](catalog/approved.json). Авторы — gpt-6.1-terra; независимая проверка смысла — gpt-6-astra. Шесть первоначально отклонённых сценариев исправлены по исходникам и повторно одобрены. Каждая запись содержит условия, ограничения, ожидаемый результат, точные цитаты, версии и SHA-256 источников.

При сборке проверяются источники, принадлежность навыка пакету, версия и соответствие записи одобрению. Изменившиеся записи исключаются до повторного ревью. Это проверка локального снимка документации, а не гарантия работоспособности установленного npm-пакета. Хеши связывают одобрение с текстом, но не удостоверяют личность рецензента.

Поиск использует лексический индекс и существующий stemmer dz-harness. Модель получает до пяти карточек и выбирает до двух ID либо уточнение/отказ. Ответ собирается из одобренных записей; сгенерированные моделью объяснения, команды и ссылки в него не попадают. Ошибочный выбор подходящего по словам сценария всё ещё возможен.

## Независимая проверка

24 вопроса составлены проверяющим до чтения карточек; это небольшой разработческий набор, не публичный бенчмарк. Сценарии не подгонялись под результаты. [Вопросы](evaluation-questions.json), [разметка покрытия](coverage.json), [поиск](retrieval-results.json), [прогон модели](cheap-picker-results.json).

| Измерение | Результат |
|---|---|
| Покрытие 18 запросов на рекомендацию | 9 полных, 1 частичный, 8 отсутствуют |
| Поиск среди полностью покрытых задач | 9/9, подходящий сценарий уже на первом месте |
| Решение всего конвейера | 21/24 совпало с независимой политикой |
| Решения непосредственно модели | 19/21; ещё 3 запроса обработаны без модели |
| Полностью покрытые запросы | 9/9 подходящих рекомендаций |
| Отсутствующее покрытие | 7/8 корректных отказов или уточнений |
| Частичное покрытие | 0/1 корректных решений |
| Неоднозначные запросы | 2/3 корректных уточнений |
| Заведомо неподходящие запросы | 3/3 корректных отказов |

Использована anthropic/claude-haiku-5.5 через OpenRouter напрямую, без E2B и без нативного agent runtime. 21 вызов: 30 716 токенов; стоимость по данным шлюза $0.00429066; медиана времени вызова около 1,44 с. Медиана по всем 24 запросам, включая обработанные без модели, около 1,34 с. Стоимость подготовки базы сильными моделями не измерена. Это единичный прогон: сравнительный выигрыш относительно прежнего советника не установлен. На девяти покрытых задачах преимущество модели над простым выбором первого результата тоже не доказано.

Три ошибки сохранены в отчёте:

- q12: сценарий оценки навыка выбран для задачи «оценить и оптимизировать» без покрытия оптимизации.
- q14: вместо отсутствующего сценария инструкций по архитектурным границам выбран BTO build.
- q21: «Мне нужен мониторинг» получил отказ из-за пустой выдачи; следовало уточнить. Это ошибка маршрутизации, модель не вызывалась.

Правильный отказ при пробеле базы не означает решение задачи пользователя. Проверка совпадения не подтверждает исполнение: некоторые навыки требуют внешних инструментов, исходных материалов, браузерного доступа или отдельного контроля.

3. Сравнить лексический top-1 с моделью по качеству отказов и уточнений; включить стоимость поддержки базы.
4. После проверки перенести в канонический исходный репозиторий и подключить как опциональный путь советника. Существующий поток остаётся доступным. Автоматическое обновление по расписанию и production endpoint в пилоте не настроены.
