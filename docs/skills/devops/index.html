API and Schema Design

Section titled “API and Schema Design”
Skill Description
api-design Design RESTful and RPC APIs following best practices. Generates OpenAPI specs, validates endpoint naming, and suggests pagination, versioning, and error-handling patterns.
graphql-schema Design GraphQL schemas with proper type hierarchies, resolvers, and query optimization. Handles N+1 detection and DataLoader patterns.

Infrastructure

Section titled “Infrastructure”
Skill Description
terraform Write and review Terraform configurations. Handles provider setup, module composition, state management, and plan review.
kubernetes Author Kubernetes manifests, Helm charts, and kustomize overlays. Covers deployments, services, ingress, RBAC, and resource limits.
docker-compose Create and optimize Docker Compose files. Handles multi-service orchestration, networking, volumes, and health checks.
deploy-on-cloudru-vm dz-original. Repo URL → running app on a Cloud.ru VM: clone & analyze the repo, ensure/synthesize a docker-compose.yml, ask for the 4 missing Cloud.ru credentials (list-zones/list-images help pick), deploy via the cloudru-vm CLI, verify, and hand back the app URL + ssh string. Triggers on “задеплой в cloud.ru”, “deploy this repo to a VM”.
nginx-config Generate and optimize Nginx configurations for reverse proxy, load balancing, SSL termination, and caching.
redis-patterns Implement Redis data structures and caching strategies. Covers pub/sub, streams, cluster setup, and eviction policies.

CI/CD and Git

Section titled “CI/CD and Git”
Skill Description
github-actions Author GitHub Actions workflows for CI/CD, testing, deployment, and release automation. Handles matrix builds, caching, and artifact management.
ci-fix Debug and repair broken CI pipelines. Analyzes logs, identifies flaky tests, resolves dependency conflicts, and fixes environment issues.
pr-review Automated pull request review. Checks code quality, test coverage, security concerns, naming conventions, and provides actionable feedback.
problem-management ITIL Problem Management — eliminate the root causes behind recurring incidents and run a prioritized known-error backlog. Distinct from incident-response (which restores service); this finds and removes the underlying defect. Triggers on “problem management”, “root cause”, “RCA”, “known error”.
itsm-itil dz-original. The connective ITIL/ITSM framework — incidents, problems, known-errors and changes (RFCs) as linked Markdown tickets with an explicit state machine, prioritized by WSJF; orchestrates incident-response + problem-management. Methodology inspired by the MIT @windyroad/itil plugin, rewritten clean-room (no plugin code/hooks/bin). Triggers on “ITIL”, “ITSM”, “WSJF”, “known error backlog”, “incident vs problem”.
git-conflict-resolve Resolve Git merge conflicts systematically. Analyzes both sides of the conflict, understands intent, and produces clean merges.

Testing

Section titled “Testing”
Skill Description
playwright-testing Write end-to-end tests with Playwright. Covers page objects, fixtures, visual regression, and cross-browser testing.
test-writer Generate unit and integration tests for any codebase. Supports vitest, jest, pytest, and Go testing. Targets boundary values and edge cases.

Data

Section titled “Data”
Skill Description
database-migration Design and execute database schema migrations. Handles up/down migrations, data transforms, zero-downtime deployments, and rollback plans.
database-review Review database schemas and queries for performance, normalization, indexing, and security (SQL injection prevention).
data-pipeline Design ETL and data pipeline architectures. Covers batch and streaming patterns, data validation, error handling, and monitoring.

Security

Section titled “Security”
Skill Description
security-audit Comprehensive security vulnerability assessment. Scans for OWASP Top 10, dependency vulnerabilities, secret exposure, and misconfiguration.
codeql-fix Resolve CodeQL security alerts. Maps alerts to code locations, explains the vulnerability, and generates targeted fixes.

Operations

Section titled “Operations”
Skill Description
incident-response Structured incident triage and resolution. Guides through severity classification, root cause analysis, mitigation, and post-mortem documentation.
observability Set up logging, metrics, and distributed tracing. Covers OpenTelemetry, Prometheus, Grafana, and structured logging patterns.
monorepo-management Manage monorepo tooling — workspace configuration, dependency graphs, selective builds, and publish orchestration.
provider-debug Debug cloud provider issues (AWS, GCP, Azure). Analyzes error codes, IAM permissions, quota limits, and service-specific gotchas.

Development

Section titled “Development”
Skill Description
debugging Systematic debugging workflows. Guides through hypothesis formation, isolation, reproduction, and fix verification. Works across languages and frameworks.
frontend-implementation Implement frontend components from designs or specifications. Covers React, Vue, Svelte, and vanilla JS with accessibility and responsive patterns.

Architecture and Process

Section titled “Architecture and Process”
Skill Description
c4-architecture Generates and validates C4 architecture diagrams — context, container, component, and code level views.
retrospective Facilitates sprint and project retrospectives — what went well, what to improve, action items with owners.
risk-assessment Scores pipeline risks, validates commits for security issues, and detects secret leaks before push.
