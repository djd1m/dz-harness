MCP Skills

The skills-mcp pack integrates AI coding agents with external services via the Model Context Protocol (MCP). Check the public package source for its current skill list.

Install

Section titled “Install”

Setup

Section titled “Setup”

MCP skills require MCP server configurations. Each skill registers the required MCP servers in your .claude/settings.json (or equivalent for your target platform).

Most MCP skills need API keys or OAuth tokens. Set them as environment variables or in your .env file:

Skills

Section titled “Skills”

Memory

Section titled “Memory”
Skill Description MCP Server
agentdb-memory Persistent memory storage and retrieval via AgentDB. Store patterns, context, and learned behaviors across sessions. Supports vector similarity search. agentdb

Search

Section titled “Search”
Skill Description MCP Server
brave-search Web search via the Brave Search API. Returns ranked results with snippets. Useful for researching libraries, finding documentation, and fact-checking. brave-search
exa-search Semantic search via the Exa API. Finds conceptually similar content rather than keyword matches. Great for finding related projects and approaches. exa
jina-reader Read and extract content from web pages via Jina. Converts HTML to clean markdown. Useful for reading documentation, blog posts, and reference material. jina-reader

Google Workspace

Section titled “Google Workspace”
Skill Description MCP Server
gmail Read and send emails via Gmail. Search inbox, read threads, compose replies, and send new messages. Requires Google OAuth. gmail
google-calendar Manage Google Calendar events. Create, update, list, and delete events. Check availability and schedule meetings. google-calendar
google-sheets Read and write Google Sheets. Access cell data, update ranges, create formulas, and manage spreadsheet structure. google-sheets
google-tasks Manage Google Tasks. Create, complete, list, and organize tasks and task lists. google-tasks

Productivity

Section titled “Productivity”
Skill Description MCP Server
clickup ClickUp project management integration. Create and update tasks, manage sprints, track time, and query project status. clickup
notion Notion pages and databases. Read, create, and update pages. Query databases, manage properties, and organize workspace content. notion
obsidian Access Obsidian vaults. Read and write notes, search by content or tags, navigate links between notes. obsidian

Developer Tools

Section titled “Developer Tools”
Skill Description MCP Server
context7 Look up library documentation via Context7. Get up-to-date API references, usage examples, and version-specific docs for popular libraries. context7
git-mcp Git operations via MCP. Clone, commit, push, branch, and manage repositories through the MCP protocol. git-mcp
gitlab GitLab integration via MCP — projects, merge requests, issues, pipelines, wiki, releases, and milestones. gitlab

Creative

Section titled “Creative”
Skill Description MCP Server
comfyui ComfyUI image generation via MCP. Execute workflows, generate images, manage models, and control VRAM usage. comfyui

Social

Section titled “Social”
Skill Description MCP Server
reddit Browse and search Reddit. Read posts and comments, search subreddits, and track discussions relevant to your project. reddit

Authentication

Section titled “Authentication”
Service Auth Method Setup
Brave Search API key BRAVE_API_KEY env var
Exa API key EXA_API_KEY env var
Jina Reader API key JINA_API_KEY env var
Gmail Google OAuth Browser flow on first use
Google Calendar Google OAuth Browser flow on first use
Google Sheets Google OAuth Browser flow on first use
Google Tasks Google OAuth Browser flow on first use
ClickUp API key CLICKUP_API_KEY env var
Notion Integration token NOTION_TOKEN env var
Obsidian Local vault path Configured in skill settings
Context7 None Works out of the box
Git MCP SSH/HTTPS Uses existing git credentials
GitLab Personal access token GITLAB_TOKEN env var
ComfyUI Local server COMFYUI_URL env var (default: localhost:8188)
Reddit None (read-only) Works out of the box
AgentDB None Local SQLite, no auth needed
