# Cloud.ru Evolution — указатель (pointer-only таргет)

Этот инструмент НЕ несёт на данном таргете ни MCP-тулов Cloud.ru, ни исполняемых
инструкций деплоя. Полная связка (MCP-сервер `cloudru-vm` на 144 тула + скилл +
детерминированный тормоз платных шагов) доставляется только на таргеты, где её можно
поставить честно: Claude Code (полный путь) и codex (после живого veto-probe).

Что можно сделать на этом таргете вручную:

1. Зарегистрируйте stdio-MCP-сервер `cloudru-vm` в конфиге ВАШЕГО инструмента сами
   (команда запуска: `cloudru-hub mcp`; креды — env `CLOUDRU_KEY_ID`/`CLOUDRU_SECRET`).
2. Прочитайте документацию пакета: `npx @dzhechkov/cloudru-hub --help`.

⚠ ПРЕДУПРЕЖДЕНИЕ: на этом таргете НЕТ детерминированного вето платных операций
(permission-ask / PreToolUse-хука). Любой вызов мутирующего тула (deploy, provision,
*_create, *_delete, vm_exec, s3_put, …) создаёт или уничтожает ПЛАТНЫЕ ресурсы без
машинного тормоза — подтверждение остаётся только на вашей дисциплине. Не подключайте
мутирующий флоу здесь; используйте Claude Code или codex, где тормоз ставится кодом
(ADR-004/ADR-005 feature hermes-claude-adaptation).

Gemini-оговорка: проверьте доступность Gemini API для ВАШЕГО аккаунта — Россия
отсутствует в списке доступности (ai.google.dev/available-regions, fetch 2026-08-04).
