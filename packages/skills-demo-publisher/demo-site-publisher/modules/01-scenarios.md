# Scenarios

Give each demo a short kebab slug and each scenario an ordered identifier such as `01-open-page`.
Each step has exactly one action. Supported actions are navigation, pointer tap, click, fill, typing,
key press, wait, screenshot, and caption. Write captions in Russian when that is the audience language.
Prefer stable `data-testid` selectors. Run the schema parser before opening a browser; invalid input
must name the JSON path that needs correction.
