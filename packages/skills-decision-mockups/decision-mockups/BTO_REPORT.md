# Текущая проверка синтетического корпуса

Дата проверки: 5 октября 2026. Этот файл заменяет исторический отчёт, чьи оценки и
проверки других страниц не доказывают качество новых учебных примеров.
Новых баллов, процента покрытия и утверждений о согласовании с владельцем здесь нет.

## Что изменено

Предметный корпус заново написан вокруг вымышленной записи на занятия:
видимая дата в списке, невидимые сроки доставки напоминания, запуск нового занятия.
Изменены роли, экран, данные, даты, числа и механика выбора. Отдельное оценочное задание
использует читальный клуб. Все примерные хосты — `example.com`.

Сохранены метод, стили и контракты взаимодействия: три вопроса находки, цена обеих
живых веток, причина рекомендации и условие для альтернативы, отбраковка мнимого
выбора, макеты только для видимой разницы, самодостаточный частичный экспорт.
Авторская и лицензионная принадлежность пакета сохранена.

## Измеренные проверки

Из корня отдельного пакета выполнено `node --test test/gate.test.mjs`:
**7 тестов прошли, 0 упало**. Исходная версия этой команды давала 4 прошедших теста;
это число тестов, а не оценка полноты или процент покрытия.

| Проверка в этом прогоне | Наблюдение |
|---|---|
| Поставляемый незаполненный шаблон | код 1 с G13 |
| Нет аргумента; нет файла | код 2 в обоих случаях |
| Объявленные импорты checker | одна строка, только Python stdlib |
| Извлечение документированных HTML-фрагментов | ровно 3, не пустой набор |
| Каждый фрагмент с реальным шаблоном; общая страница | 4 вызова checker, каждый код 0 / GREEN |
| Порядок развилок | ожидаемые `lesson-date`, `lesson-reminder`, `lesson-launch` |
| Модульный и инлайн-пикер | частичный и полный экспорт совпали с двумя блоками в examples |
| Дополнительные переходы обоих пикеров | Enter/Space, повторный клик, смена варианта, восстановление состояния и сброс прошли |

Тест исполняет настоящий поставляемый JavaScript через Node VM с небольшим адаптером
DOM, построенным из реальной разметки примеров. Он не подменяет экспорт самостоятельной
функцией и не изображает полный браузер.

Сравнение с базовой версией: Python AST checker совпадает без атрибутов координат;
исполняемая часть `picker.js` от `(function (global) {` совпадает байт в байт;
инлайн-скрипт и блок CSS шаблона совпадают байт в байт. Изменения этих файлов затрагивают
комментарии или учебное содержимое HTML, не правила проверки и не формат экспорта.

Нормальная синхронизация от самостоятельного канонического пакета использует:

```bash
node scripts/sync-canonical-skill.mjs decision-mockups --from packages/@dzhechkov/skills-decision-mockups/decision-mockups --check
```

Она обнаружила две проекции и сообщила об их совпадении с каноном. Это проверка трёх
тел навыка, а не проверка всего монорепозитория. `git diff --check` не сообщил ошибок.

## Ограничения

- Зелёный checker доказывает структурные требования, но не полезность выбора, истинность
  оценки, понятность языка или отсутствие любых возможных ассоциаций с другими случаями.
- Пять запросов в `evals/eval-cases.md` — будущие поведенческие задания; новый балл по ним
  не измерялся. Их нельзя выдавать за уже пройденные оценки.
- Не выполнен браузерный прогон светлой/тёмной темы, узкого экрана, реального буфера обмена
  и вспомогательных технологий. Кнопки имеют `aria-pressed`; полной radio-семантики нет.
- Навык поддерживает объяснение без решений, но неизменённый checker требует группу (G6a).
  Это ограничение указано в SKILL и оценочном задании; фиктивный выбор не добавлялся.
- Поле `tier` сохраняет прежнюю классификацию проекта, не означает новую оценку корпуса.
  Общий skill-creator quick_validate отвергает это нестандартное поле; исходный frontmatter
  тоже не соответствовал его схеме. Отдельно это совместимость схемы, не вердикт checker.
- Проверки фактических npm-архивов, подписей и независимая смысловая оценка — отдельные
  этапы выпуска; их результаты фиксируются в отдельных квитанциях.
- Новый выпуск не заменяет байты, опубликованные под более ранними версиями npm.
