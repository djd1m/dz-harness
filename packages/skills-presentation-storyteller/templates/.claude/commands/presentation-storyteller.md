# Presentation Storyteller: продающая презентация + storytelling-скрипт

## Использование
```
/presentation-storyteller [тема / продукт / питч]
```

## Аргумент
$ARGUMENTS

## Действия

1. **Загрузи скилл:** Прочитай `.claude/skills/presentation-storyteller/SKILL.md`
2. **Уточни задачу** (при необходимости): `.claude/skills/explore/SKILL.md`.
3. **Верифицированный research** источников: `.claude/skills/goap-research-ed25519/SKILL.md`.
4. **Сгенерируй 3 артефакта:**
   - `presentation-outline.md` — план с тезисами по каждому пункту;
   - `presentation-full.md` — полная презентация в Markdown со ссылками на источники;
   - `sources-index.md` — индекс верифицированных источников.
5. **Подстрочник «Как рассказывать?»** — связная история на каждый слайд (storytelling-фреймворки: AIDA, Hero's Journey, Problem-Solution; см. `references/`).

## Output
Продающая презентация с верифицированными источниками + speaker-скрипт.
