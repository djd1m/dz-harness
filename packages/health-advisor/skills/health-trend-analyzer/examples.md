# Анализатор трендов здоровья - Примеры использования

## Пример 1: Общий анализ трендов здоровья

### Ввод пользователя
```
Что изменилось в моём здоровье за последние 3 месяца?
```

### Выполнение Claude

1. **Определение временного диапазона**: Последние 3 месяца (2025-10-01 по 2025-12-31)
2. **Чтение данных**:
   - profile.json → История веса: 70 кг → 68,5 кг
   - symptoms/ → Головная боль 12 раз, усталость 8 раз, бессонница 6 раз
   - mood/ → Средняя оценка настроения 6,8/10, средний сон 6,5 часов
   - medication-logs/ → Приверженность 78% (8 пропусков)
   - medical_records/ → Холестерин 240→210, глюкоза 5,6→5,4
3. **Анализ трендов**:
   - Вес: Снижение на 2,3 кг (-3,2%), положительный тренд
   - Симптомы: Снижение частоты головной боли (на 4 раза меньше по сравнению с предыдущим периодом)
   - Анализы: Улучшение холестерина (-30 мг/дл)
   - Приверженность: Амлодипин только 65%, необходимо улучшение
4. **Корреляционный анализ**:
   - Продолжительность сна ↔ Оценка настроения: r=0,78 (сильная положительная корреляция)
   - Приверженность приёму лекарств ↔ Частота симптомов: r=-0,62 (средняя отрицательная корреляция)
5. **Формирование HTML-отчёта**: Сохранение в `data/health-reports/health-trend-report-2025-12-31.html`

### Результат

**Текстовый отчёт**:
```
Отчёт по анализу трендов здоровья
━━━━━━━━━━━━━━━━━━━━━━━━━━
Время формирования: 2025-12-31
Период анализа: последние 3 месяца

📊 Общая оценка
━━━━━━━━━━━━━━━━━━━━━━━━━━
Улучшение: Управление весом, уровень холестерина
Стабильно: Контроль глюкозы, эмоциональное состояние
Требует внимания: Приверженность приёму лекарств, качество сна

[Подробный анализ трендов...]
```

**HTML-отчёт с визуализацией**:
- 📊 Линейный график веса/ИМТ: Показывает постепенное снижение веса
- ⚠️ Столбчатая диаграмма частоты симптомов: Головная боль (красный), усталость (оранжевый), бессонница (жёлтый)
- 💊 Панель приверженности приёму лекарств: 78%, оранжевое предупреждение
- 🧪 Линейный график результатов анализов: Кривая снижения холестерина, маркеры референсных линий
- 🔗 Тепловая карта корреляций: Сильная корреляция сна и настроения, отрицательная корреляция лекарств и симптомов
- 😊 Площадная диаграмма настроения и сна: Двойные оси Y демонстрируют взаимосвязь

### Анализ и рекомендации

**✅ Положительные изменения**:
1. Снижение веса на 2,3 кг, ИМТ с 23,8 до 23,1, в пределах здорового диапазона
2. Холестерин с 240 до 210 мг/дл, значительное улучшение
3. Частота головной боли снизилась с 16 до 12 раз по сравнению с предыдущим периодом

**⚠️ Требует внимания**:
1. Приверженность приёму амлодипина всего 65%, много пропусков
2. Средняя продолжительность сна 6,5 часов, немного ниже рекомендуемых 7-8 часов
3. Бессонница всё ещё отмечается 6 раз, влияет на качество жизни

**💡 Рекомендации**:
1. Установить напоминание о приёме амлодипина (рекомендуемое время: каждый вечер в 20:00)
2. Установить регулярный режим сна (фиксированное время отхода ко сну/пробуждения)
3. Повторная проверка липидного профиля через 3 месяца для оценки устойчивости улучшения холестерина
4. Рассмотреть использование гигиены сна для улучшения бессонницы

## Пример 2: Анализ паттернов симптомов

### Ввод пользователя
```
Почему у меня постоянно болит голова? Проанализируй мои паттерны симптомов
```

### Выполнение Claude

1. **Чтение данных о симптомах**:
   - За последние 3 месяца: 12 записей о головной боли
   - Степень тяжести: умеренная 7 раз, сильная 5 раз
   - Продолжительность: в среднем 4 часа
   - Триггеры: стресс (4 раза), недостаток сна (3 раза), голодание (2 раза)

2. **Анализ временных паттернов**:
   - С понедельника по пятницу: 8 раз (рабочий стресс)
   - Выходные: 4 раза (относительно меньше)
   - Распределение по времени: 14:00-16:00 (5 раз), 20:00-22:00 (4 раза)

3. **Корреляционный анализ**:
   - Частота головной боли ↔ Продолжительность сна: r=-0,68 (средняя отрицательная корреляция)
   - Частота головной боли ↔ Уровень стресса: r=0,72 (средняя положительная корреляция)
   - Частота головной боли ↔ Приверженность приёму лекарств: r=-0,45 (слабая отрицательная корреляция)

4. **Обнаружение тренда**:
   - Октябрь: 5 раз
   - Ноябрь: 4 раза
   - Декабрь: 3 раза
   - Тренд: 📉 Снижение частоты (улучшение)

### Результат

**Текстовый отчёт**:
```
Отчёт по анализу паттернов симптомов
━━━━━━━━━━━━━━━━━━━━━━━━━━
Анализируемый симптом: Головная боль
Временной диапазон: последние 3 месяца

⚠️ Обзор симптома
├─ Общее количество: 12 раз
├─ Средняя степень тяжести: Умеренная
├─ Средняя продолжительность: 4 часа
└─ Тренд: 📉 Снижение частоты (улучшение)

📅 Временной паттерн
├─ Чаще в рабочие дни: Понедельник–пятница (8 раз)
├─ Пиковое время: 14:00-16:00 (5 раз)
└─ Помесячный тренд: Снижение (5→4→3)

🔍 Потенциальные триггеры
├─ Стресс (корреляция 72%): 4 раза
├─ Недостаток сна (корреляция 68%): 3 раза
└─ Голодание (корреляция 55%): 2 раза

💡 Рекомендации по улучшению
├─ Продолжать: Текущий тренд показывает улучшение
├─ Управление стрессом: Стратегии снижения стресса в рабочие дни
├─ Улучшение сна: Увеличить продолжительность сна до 7-8 часов
└─ Регулярное питание: Избегать длительного голодания
```

**HTML-отчёт с визуализацией**:
- ⚠️ Столбчатая диаграмма частоты симптомов: Головная боль (красный, 12 раз), другие симптомы (менее частые)
- 📅 Тепловая карта времени симптомов: Рабочие дни — тёмный цвет (высокая частота), выходные — светлый (низкая частота)
- 🔗 Столбчатая диаграмма корреляций: Стресс (0,72), недостаток сна (-0,68), голодание (0,55)
- 📉 Линейный график тренда: Октябрь (5) → Ноябрь (4) → Декабрь (3), стрелка вниз

### Анализ и рекомендации

**Характеристики симптома**:
- Признаки **головной боли напряжения**: Чаще в рабочие дни, связана со стрессом
- **Тренд улучшения**: Снижение с 5 раз в октябре до 3 раз в декабре

**Анализ триггеров**:
1. **Рабочий стресс** (основной триггер): 8 раз с понедельника по пятницу, пик во второй половине дня
2. **Недостаток сна**: Средняя продолжительность сна в ночь перед головной болью — всего 6,2 часа
3. **Нерегулярное питание**: 2 случая головной боли на фоне гипогликемии при голодании

**💡 Рекомендации**:
1. **Управление стрессом**:
   - 5-минутный перерыв каждые 2 часа в рабочие дни
   - Расслабляющие активности во второй половине дня (14:00-16:00)
   - Рассмотреть освоение техник глубокого дыхания и медитации

2. **Улучшение сна**:
   - Увеличить продолжительность сна до 7-8 часов
   - Фиксированный режим сна
   - Избегать экранов за 1 час до сна

3. **Корректировка питания**:
   - Регулярное трёхразовое питание, избегать длительного голодания
   - Подготовить здоровые перекусы на вторую половину дня
   - Поддерживать достаточный уровень гидратации

4. **Мониторинг**:
   - Продолжать вести дневник головной боли
   - Оценить улучшение через 1 месяц
   - При отсутствии улучшения или ухудшении рекомендуется обратиться к врачу

## Пример 3: Анализ эффективности лекарственного препарата

### Ввод пользователя
```
Эффективен ли мой антигипертензивный препарат? Проанализируй эффект лечения
```

### Выполнение Claude

1. **Чтение данных о лекарствах**:
   - Текущий препарат: Амлодипин 5 мг, 2 раза в день
   - Дата начала: 2025-09-15 (2,5 месяца назад)
   - Журнал приёма: Должен был принять 150 раз, фактически принял 98 раз (приверженность 65%)

2. **Чтение данных об артериальном давлении**:
   - До начала приёма (сентябрь): в среднем 158/95 мм рт.ст.
   - 1 месяц приёма (октябрь): в среднем 142/88 мм рт.ст.
   - 2 месяца приёма (ноябрь): в среднем 135/85 мм рт.ст.
   - 3 месяца приёма (декабрь): в среднем 132/82 мм рт.ст.

3. **Чтение данных о симптомах**:
   - Головокружение (симптом, связанный с лекарством): до приёма 8 раз/месяц → после приёма 3 раза/месяц
   - Учащённое сердцебиение: до приёма 5 раз/месяц → после приёма 1 раз/месяц

4. **Оценка эффективности**:
   - **Контроль давления**: Систолическое давление снизилось на 26 мм рт.ст., диастолическое на 13 мм рт.ст. ✅
   - **Процент достижения цели**: С 0% до 75% (9/12 измерений <140/90)
   - **Улучшение симптомов**: Заметное снижение частоты головокружения и сердцебиения ✅

5. **Анализ приверженности**:
   - Общая приверженность: 65% ⚠️ (цель ≥90%)
   - Паттерн пропусков: Вечерняя доза пропускается чаще (20 раз vs утренняя 7 раз)
   - Анализ причин: Забывает после ужина (15 раз), обед вне дома (5 раз), рабочая занятость (7 раз)

### Результат

**Текстовый отчёт**:
```
Отчёт по анализу эффективности лекарственного препарата
━━━━━━━━━━━━━━━━━━━━━━━━━━
Препарат: Амлодипин 5 мг
Способ применения: 2 раза в день
Дата начала: 2025-09-15
Период анализа: 2,5 месяца после начала приёма

📊 Эффект контроля давления
├─ Систолическое: 158 → 132 мм рт.ст. (-26, улучшение ✅)
├─ Диастолическое: 95 → 82 мм рт.ст. (-13, улучшение ✅)
├─ Процент достижения цели: 0% → 75% (9/12 раз < 140/90)
└─ Оценка: Препарат эффективен, хороший контроль давления

⚠️ Улучшение симптомов
├─ Головокружение: 8 раз/мес. → 3 раза/мес. (снижение на 62%)
├─ Сердцебиение: 5 раз/мес. → 1 раз/мес. (снижение на 80%)
└─ Оценка: Значительное улучшение связанных симптомов

💊 Приверженность приёму
├─ Общая приверженность: 65% (98/150 раз) ⚠️
├─ Утренняя доза: 93% (хорошо)
├─ Вечерняя доза: 48% (требует улучшения)
└─ Основная причина пропусков: Забывает после ужина (15 раз)

💡 Рекомендации по улучшению
├─ Продолжать приём: Хороший эффект контроля давления
├─ Повысить приверженность: Установить вечернее напоминание о приёме
├─ Действия при пропуске: Если с момента планового приёма прошло <2 часов, можно принять
└─ Регулярные проверки: Оценка стабильности контроля давления через 1 месяц
```

**HTML-отчёт с визуализацией**:
- 📊 Линейный график тренда давления: До приёма (158/95) → Помесячное снижение до (132/82)
- 📈 Столбчатая диаграмма достижения цели: До приёма 0% → После приёма 75%
- 💊 Панель приверженности: 65% (оранжевый), утро 93% (зелёный) vs вечер 48% (красный)
- ⚠️ График улучшения симптомов: Сравнение частоты головокружения и сердцебиения (до и после приёма)
- 🕒 Тепловая карта пропусков: Вечерний период (20:00) тёмный цвет (частые пропуски)

### Анализ и рекомендации

**✅ Эффективность препарата**:
1. **Выраженный гипотензивный эффект**: Систолическое давление снизилось на 26 мм рт.ст., диастолическое на 13 мм рт.ст.
2. **Повышение процента достижения цели**: С 0% до 75%, приближение к целевому контролю (<140/90)
3. **Улучшение симптомов**: Значительное уменьшение головокружения, сердцебиения и других симптомов, связанных с гипертензией

**⚠️ Проблемы с приверженностью**:
1. **Общий показатель низкий**: 65% приверженность ниже целевых 90%
2. **Вечерние пропуски**: Показатель пропуска вечерней дозы достигает 52% (20 раз/39 раз)
3. **Основная причина**: Забывает после ужина (15 раз, 53%)

**💡 Рекомендации по улучшению**:

**1. Повышение вечерней приверженности**:
- Установить вечернее напоминание о приёме (рекомендуемое время 20:00, через 30 минут после ужина)
- Разместить лекарства на видном месте (обеденный стол, тумбочка)
- Использовать таблетницу с предварительной раскладкой на неделю

**2. Действия при пропуске**:
- Если обнаружен пропуск и с планового времени прошло <2 часов, можно принять немедленно
- Если прошло более 2 часов, пропустить эту дозу и продолжить по плану
- Избегать приёма двойной дозы в следующий раз

**3. План мониторинга**:
- Продолжать ежедневный мониторинг давления, вести дневник
- Через 1 месяц оценить стабильность контроля давления и улучшение приверженности
- Если приверженность повысится до 90%, но давление всё ещё не достигнет цели, рекомендуется обратиться к врачу для корректировки дозы

**4. Поддержка образом жизни**:
- Диета с ограничением соли (<6 г/день)
- Регулярные физические нагрузки (150 минут средней интенсивности в неделю)
- Ограничение алкоголя (мужчины <25 г/день, женщины <15 г/день)

## Пример 4: Анализ трендов веса/ИМТ

### Ввод пользователя
```
Я худею? Проанализируй мои тренды веса
```

### Выполнение Claude

1. **Чтение данных о весе**: 28 записей за 3 месяца (70,8 кг -> 68,5 кг)
2. **Расчёт ИМТ**: 23,9 -> 23,1 (-0,8)
3. **Анализ трендов**: Снижение на 2,3 кг (-3,2%), скорость 0,18 кг/неделю
4. **Связь с питанием**: 1650 ккал/день, 75 г белка, 150 мин тренировок/неделю
5. **Поэтапный анализ**: Замедление скорости снижения (1,3 -> 0,7 -> 0,3 кг/мес)

### Ключевые выводы

- Устойчивое снижение веса, ИМТ в нормальном диапазоне
- Скорость снижения замедляется (возможно плато из-за метаболической адаптации)
- Рекомендации: увеличить интенсивность тренировок, поддерживать белок 75-100 г/день, улучшить сон до 7-8 часов
- HTML-отчёт включает: график тренда веса, график ИМТ, диаграмму по этапам, графики питания и тренировок

## Пример 5: Корреляционный анализ

### Ввод пользователя
```
Как связаны моё настроение и сон? Проанализируй корреляцию
```

### Выполнение Claude

1. **Чтение данных о настроении**: 82 дня из 90 (91%), средняя 6,8/10
2. **Чтение данных о сне**: средняя 6,5 часов, качество: хорошее 6, среднее 48, плохое 28
3. **Расчёт корреляций**: сон-настроение r=0,78, качество сна r=0,65, стресс r=-0,52, тренировки r=0,43
4. **Выявление паттернов**: высокое настроение (>=8) = средний сон 7,2 ч; низкое (<=5) = 5,4 ч
5. **Анализ временных рядов**: период спада (середина октября, сон 5,2 ч) и подъёма (начало декабря, сон 7,5 ч)

### Ключевые выводы

- Сильная корреляция сна и настроения (r=0,78): каждый доп. час сна = +1,5 балла настроения
- Рабочий стресс -- второй по значимости фактор (r=-0,52)
- Рекомендации: увеличить сон до 7-8 ч, установить регулярный режим, управление стрессом
- HTML-отчёт включает: диаграмму рассеяния, площадную диаграмму, столбчатую диаграмму корреляций, график временных рядов

## Сводка ключевых слов-триггеров

**Общие триггеры**:
- Тренды здоровья, изменения здоровья, состояние здоровья, изменения организма
- Анализ, сводка, оценка, обзор
- За последние X месяцев, недавно, тренды

**Триггеры по конкретным измерениям**:
- Вес, ИМТ, похудение, полнота/худоба
- Симптомы, головная боль, плохое самочувствие
- Эффект лекарств, приём лекарств, приверженность
- Анализы, обследование, показатели
- Настроение, эмоции, сон
- Связь, взаимосвязь, влияние

**Триггеры по типу анализа**:
- Паттерн, закономерность, частота
- Тренд, изменение, рост/снижение
- Корреляция, связь, влияние
- Эффективность, результат, улучшение
