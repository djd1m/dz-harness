# Навык анализа снижения веса

## Обзор

Навык анализа снижения веса предоставляет комплексные инструменты для управления процессом похудения. Он выполняет расчёт состава тела (ИМТ, процент жира, окружности), определяет базовый метаболизм по трём формулам (Harris-Benedict, Mifflin-St Jeor, Katch-McArdle), рассчитывает TDEE и энергетический дефицит, а также управляет фазами снижения веса с учётом медицинских ограничений безопасности.

### Функции

#### 1. Анализ состава тела

**Расчёт и классификация ИМТ**
- ИМТ = Вес(кг) / Рост(м)^2
- Классификация по азиатским стандартам ВОЗ: недостаточный вес (ИМТ < 18.5), норма (18.5-24), избыточный вес (24-28), ожирение (>= 28)

**Оценка процента жира в организме**
- Мужчины: 15-20% (норма), 20-25% (повышенный), >25% (ожирение)
- Женщины: 20-25% (норма), 25-30% (повышенный), >30% (ожирение)

**Анализ окружностей**
- Окружность талии: мужчины <90 см - норма, женщины <85 см - норма
- Соотношение талия/бёдра: мужчины <0.9 - норма, женщины <0.85 - норма

**Расчёт идеального веса**
- Метод ИМТ: Идеальный вес = Рост(м)^2 x 22
- Модифицированная формула Брока: Идеальный вес = (Рост(см) - 100) x 0.9

#### 2. Расчёт скорости метаболизма

**Три формулы**
- Harris-Benedict (оригинальная версия 1919 г.)
- Mifflin-St Jeor (рекомендуемая, более точная)
- Katch-McArdle (на основе безжировой массы тела)

**Расчёт TDEE** = BMR x Коэффициент активности (от сидячего образа жизни 1.2 до очень высокой активности 1.9)

#### 3. Управление энергетическим дефицитом

- Дефицит = TDEE - Фактическое потребление + Расход на физическую активность
- "1 кг жира ~ 7700 ккал"
- Безопасная скорость: 0.5-1 кг/неделю (дефицит 500-1000 ккал)

**Границы безопасности по калорийности**
- Минимум для мужчин: 1500 ккал/день
- Минимум для женщин: 1200 ккал/день
- Абсолютный минимум: BMR x 1.2

#### 4. Управление фазами

- Фаза снижения веса: отслеживание изменений массы тела
- Фаза плато: колебания веса <0.5 кг в течение более 2 недель
- Фаза поддержания: диапазон +/- 2 кг от целевого веса

### Источники данных

1. **Фитнес-трекер** (`data/fitness-tracker.json`): вес, состав тела, скорость метаболизма
2. **Трекер питания** (`data/nutrition-tracker.json`): потребление калорий, энергетический дефицит
3. **Журнал здоровья** (`data/health-logs/YYYY-MM/YYYY-MM-DD.json`): ежедневные записи

## Инструкция по использованию

Навык выполняется последовательно в 7 этапов. Каждый этап генерирует промежуточный результат, который используется на следующем этапе.

### Этап 1. Сбор данных профиля

Считать данные пациента из `profile.json` или запросить вручную: возраст, пол, рост, текущий вес, целевой вес, уровень физической активности, наличие хронических заболеваний.

```bash
/fitness:weightloss-setup --weight 75 --height 175 --age 52 --gender male
```

### Этап 2. Анализ состава тела

Рассчитать ИМТ, процент жира (при наличии данных), идеальный вес по методу ИМТ и формуле Брока. Классифицировать статус по ВОЗ.

### Этап 3. Расчёт базового метаболизма (BMR)

Применить все три формулы и выбрать наиболее подходящую:

- **Harris-Benedict** (1919, пересмотрена Roza & Shizgal 1984):
  - Мужчины: BMR = 88.362 + (13.397 x вес_кг) + (4.799 x рост_см) - (5.677 x возраст)
  - Женщины: BMR = 447.593 + (9.247 x вес_кг) + (3.098 x рост_см) - (4.330 x возраст)
- **Mifflin-St Jeor** (1990, рекомендуемая ADA):
  - Мужчины: BMR = (10 x вес_кг) + (6.25 x рост_см) - (5 x возраст) + 5
  - Женщины: BMR = (10 x вес_кг) + (6.25 x рост_см) - (5 x возраст) - 161
- **Katch-McArdle** (требуется процент жира):
  - BMR = 370 + (21.6 x безжировая_масса_кг)

```bash
/fitness:weightloss-bmr --formula mifflin
```

### Этап 4. Расчёт TDEE и энергетического дефицита

Определить общий суточный расход энергии (TDEE = BMR x коэффициент активности) и рассчитать безопасный дефицит для достижения целевого веса.

| Уровень активности       | Коэффициент |
|---------------------------|-------------|
| Сидячий образ жизни       | 1.2         |
| Лёгкая активность (1-3 д) | 1.375       |
| Умеренная активность (3-5 д) | 1.55     |
| Высокая активность (6-7 д) | 1.725      |
| Очень высокая активность  | 1.9         |

```bash
/nutrition:weightloss-track --intake 1800 --exercise 350
```

### Этап 5. Определение фазы и прогноза

Определить текущую фазу (снижение, плато, поддержание) на основе динамики веса за последние 2 недели. Рассчитать прогнозируемую дату достижения целевого веса.

```bash
/fitness:weightloss-plateau-check
```

### Этап 6. Формирование рекомендаций

Сгенерировать персонализированные рекомендации по питанию и физической активности с учётом текущей фазы, медицинских ограничений и предпочтений пациента.

### Этап 7. Генерация отчёта

Сформировать итоговый отчёт в формате Markdown со всеми расчётами, графиками динамики и рекомендациями.

```bash
/fitness:weightloss-report
```

## Обработка ошибок

| Ситуация                                   | Поведение                                                         |
|--------------------------------------------|-------------------------------------------------------------------|
| **Отсутствуют обязательные поля**          | Навык запрашивает недостающие данные перед выполнением расчётов    |
| **Возраст < 18 лет**                      | Отказ с сообщением: навык не предназначен для несовершеннолетних  |
| **ИМТ < 16 (критический дефицит веса)**   | Предупреждение: рекомендации по снижению веса не генерируются; направление к врачу |
| **ИМТ > 40 (морбидное ожирение)**         | Предупреждение: необходимо наблюдение врача; стандартные формулы могут быть неточны |
| **Целевой вес ниже ИМТ 18.5**             | Отказ: целевой вес ниже границы нормы; запрос корректировки цели  |
| **Дефицит > 1000 ккал/день**              | Предупреждение: чрезмерный дефицит; автоматическое ограничение до 1000 ккал |
| **Потребление ниже минимума (1200/1500)**  | Блокировка рекомендации: потребление ниже безопасного минимума    |
| **Нереалистичные сроки (>1 кг/неделю)**    | Предупреждение: рекомендуемая скорость 0.5-1 кг/неделю           |
| **Противоречивые данные веса**             | Запрос повторного взвешивания при отклонении >2 кг между днями    |
| **Беременность / кормление грудью**        | Отказ: навык не применяется; направление к врачу                  |
| **Расстройства пищевого поведения в анамнезе** | Усиленные предупреждения; рекомендация работы с психологом    |

## Безопасность и конфиденциальность

### Защита данных пациента

- Все данные пациента хранятся **локально** в файловой системе пользователя.
- Данные **никогда не отправляются** на внешние серверы или API.
- Файлы профиля и журналов содержат медицинскую информацию и должны быть защищены соответствующими правами доступа.

### Рекомендации по безопасности

- Используйте идентификаторы пациентов вместо реальных имён в файлах данных.
- Храните файлы `profile.json` и журналы в директории с ограниченным доступом (chmod 700).
- Не включайте файлы данных в публичные репозитории.
- При передаче отчётов убедитесь в анонимизации данных.
- Регулярно удаляйте устаревшие журналы, которые больше не нужны для анализа.

### Соответствие стандартам

- Навык соответствует принципу минимизации данных: запрашиваются только данные, необходимые для расчётов.
- Данные не используются для обучения моделей или других целей, кроме генерации отчёта для конкретного пациента.

## Анти-паттерны

- **Экстремальные дефициты**: не следует рекомендовать или допускать калорийность ниже безопасных минимумов (1200/1500 ккал)
- **Игнорирование состава тела**: нельзя ориентироваться только на вес без учёта соотношения жировой и мышечной массы
- **Универсальные формулы**: не следует применять одну формулу BMR ко всем пользователям без учёта уровня активности и состава тела
- **Ложная линейность**: нельзя предполагать линейное снижение веса без учёта метаболической адаптации и фаз плато
- **Игнорирование медицинских противопоказаний**: не следует генерировать рекомендации без проверки наличия хронических заболеваний, беременности или расстройств пищевого поведения

## Зависимости

- **Инструменты**: Read, Grep, Glob, Write
- **Источники данных**: `fitness-tracker.json`, `nutrition-tracker.json`, ежедневные журналы здоровья
- **Формулы**: Harris-Benedict, Mifflin-St Jeor, Katch-McArdle (BMR); коэффициенты физической активности (TDEE)
- **Стандарты**: классификация ИМТ по азиатским стандартам ВОЗ, нормы процента жира в организме

## Дисклеймер

Данный навык предназначен для информационных и образовательных целей. Он **не заменяет** консультацию квалифицированного врача, эндокринолога или диетолога. Все рекомендации по снижению веса должны быть согласованы с лечащим врачом, особенно при наличии хронических заболеваний, приёме лекарственных препаратов или в особых физиологических состояниях (беременность, кормление грудью).
