# Навык анализа реабилитационных тренировок

## Обзор

Навык анализа реабилитационных тренировок предоставляет комплексный инструмент для отслеживания восстановления после травм и операций. Он оценивает динамику функциональных показателей (амплитуда движений, мышечная сила, баланс), анализирует паттерны боли, рассчитывает приверженность тренировочному плану и управляет фазами реабилитации с прогнозированием достижения целей.

## Основные функции

Навык анализа реабилитационных тренировок предоставляет комплексные возможности анализа данных реабилитации, помогая пользователям отслеживать прогресс восстановления, выявлять паттерны улучшения и оптимизировать тренировочные планы.

**Основные функциональные модули:**

1. **Анализ прогресса реабилитации** - Оценка тенденций функционального улучшения и эффективности реабилитации
2. **Кривая функционального улучшения** - Визуализация изменений показателей амплитуды движений (ROM), мышечной силы, баланса
3. **Распознавание паттернов боли** - Анализ тенденций изменения оценки боли и выявление триггерных факторов
4. **Оценка достижения целей** - Отслеживание выполнения реабилитационных целей
5. **Анализ фаз реабилитации** - Оценка прогресса на текущей фазе и готовности к переходу на следующую
6. **Оценка приверженности тренировкам** - Анализ выполнения тренировочного плана

## Условия активации

Навык автоматически активируется в следующих случаях:

1. Пользователь использует `/rehab progress` для просмотра прогресса реабилитации
2. Пользователь использует `/rehab analysis` для проведения анализа реабилитации
3. Пользователь использует `/rehab trends` для просмотра анализа трендов
4. Пользователь использует `/rehab report` для генерации отчёта о реабилитации

## Этапы выполнения

### Этап 1: Чтение данных
Чтение файлов данных реабилитации:
- `data/rehabilitation-tracker.json` - Основная реабилитационная карта
- `data/rehabilitation-logs/YYYY-MM/YYYY-MM-DD.json` - Ежедневные журналы тренировок

**Валидация данных:**
- Проверка наличия файлов
- Проверка целостности структуры данных
- Подтверждение достаточного количества точек данных для анализа (рекомендуется минимум 3 оценки или 10 дней записей тренировок)

### Этап 2: Анализ тенденций функциональной оценки

**Анализ амплитуды движений (ROM):**
```
- Анализ измерений ROM в разные временные точки
- Расчёт скорости улучшения ROM (градусы/неделю)
- Выявление плато или регресса ROM
- Прогнозирование времени достижения целевого ROM
- Сравнение с целевым диапазоном
```

**Анализ улучшения мышечной силы:**
```
- Отслеживание изменений уровня мышечной силы (баллы ММТ)
- Выявление паттернов роста силы
- Сравнение скорости восстановления разных мышечных групп
- Оценка мышечного дисбаланса
```

**Анализ функции баланса:**
```
- Тенденции результатов тестов баланса
- Улучшение времени стояния на одной ноге
- Оценка стабильности баланса
- Изменение риска падений
```

### Этап 3: Анализ паттернов боли

**Временной анализ боли:**
```
- Анализ тенденций утренней боли
- Анализ тенденций боли после активности
- Выявление паттернов усиления/ослабления боли
- Корреляция боли с интенсивностью тренировок
```

**Выявление триггерных факторов боли:**
```
- Связь конкретных упражнений с болью
- Корреляция интенсивности тренировок и боли
- Связь типов активности с болью
- Влияние временных факторов на боль
```

### Этап 4: Расчёт приверженности тренировкам

**Показатели приверженности:**
```
Приверженность = (Фактическое количество тренировок / Запланированное количество тренировок) x 100%
```

**Измерения анализа:**
- Недельная приверженность
- Месячная приверженность
- Общая приверженность
- Приверженность по разным типам тренировок

### Этап 5: Оценка достижения целей

**Отслеживание прогресса целей:**
- Расчёт процента выполнения каждой цели
- Прогнозирование времени достижения цели
- Выявление отстающих целей
- Рекомендации по корректировке целей

### Этап 6: Оценка фазы реабилитации

**Анализ текущей фазы:**
- Выполнение целей фазы
- Готовность к переходу на следующую фазу
- Рекомендации по переходу между фазами

### Этап 7: Генерация отчёта

Вывод включает:
- Сводку прогресса реабилитации
- Тенденции функционального улучшения
- Состояние контроля боли
- Оценку приверженности тренировкам
- Оценку достижения целей
- Рекомендации по фазам
- Персонализированные рекомендации

## Алгоритмы анализа

### 1. Анализ тенденций улучшения

**Линейный регрессионный анализ:**
```
Аппроксимация тенденции функционального улучшения методом наименьших квадратов
Скорость улучшения = (Текущее значение - Базовое значение) / Временной интервал
```

**Распознавание паттернов улучшения:**
- Линейное улучшение: стабильное непрерывное улучшение
- Ступенчатое улучшение: быстрое улучшение после периода плато
- Плато: стагнация улучшения
- Регресс: снижение функции (требует внимания)

### 2. Временной анализ боли

**Расчёт скользящего среднего:**
```
7-дневная скользящая средняя боли = sum(боль за последние 7 дней) / 7
```

**Определение тенденции боли:**
- Улучшение: снижение оценки боли >= 20%
- Стабильно: изменение оценки боли <20%
- Ухудшение: повышение оценки боли >= 20%

### 3. Расчёт приверженности

```
Общая приверженность = (Фактическое количество дней тренировок / Запланированное количество дней) x 100%

Приверженность по типу тренировки = (Фактическое выполнение данного типа / Запланированное выполнение данного типа) x 100%
```

**Оценка приверженности:**
- Отлично: >= 90%
- Хорошо: 75-89%
- Удовлетворительно: 60-74%
- Требует улучшения: <60%

### 4. Прогнозирование достижения целей

**Линейная экстраполяция:**
```
Прогнозируемое время = Текущая дата + ((Целевое значение - Текущее значение) / Скорость улучшения)
```

**Учитываемые факторы:**
- Недавняя скорость улучшения
- История периодов плато
- Приверженность тренировкам

### 5. Оценка готовности к переходу между фазами

**Оценка готовности:**
```
Готовность = (Количество достигнутых целей фазы / Общее количество целей фазы) x 100%

Готовность >= 80%: Рекомендуется переход на следующую фазу
Готовность 60-79%: Возможен переход на следующую фазу с осторожностью
Готовность < 60%: Рекомендуется продолжить текущую фазу
```

## Безопасность и конфиденциальность

### Принципы безопасности данных

1. **Локальное хранение**
   - Все данные реабилитации хранятся только на локальном устройстве пользователя
   - Данные не загружаются на облачные серверы
   - Данные не передаются третьим лицам

2. **Защита конфиденциальности**
   - Личная медицинская информация строго конфиденциальна
   - Файлы данных не содержат персональных идентификационных данных
   - Пользователь полностью контролирует доступ к данным

3. **Целостность данных**
   - Исходные данные не модифицируются
   - Результаты анализа основаны на реальных данных
   - Поддерживается экспорт и резервное копирование данных

### Границы медицинской безопасности

**Ограничения системы:**
- Не предоставляет конкретные программы реабилитационных тренировок
- Не заменяет профессиональное руководство реабилитолога
- Не диагностирует травмы или осложнения
- Не корректирует план фаз реабилитации
- Не прогнозирует сроки восстановления
- Не обрабатывает острую боль или травмы

**Возможности системы:**
- Предоставление анализа данных и выявление тенденций
- Отслеживание прогресса и управление целями
- Предоставление общих рекомендаций по реабилитации
- Напоминания о необходимости профессиональной реабилитационной консультации
- Запись данных тренировок и оценок
- Генерация отчётов о прогрессе реабилитации

**Важное примечание:**
- Все планы реабилитационных тренировок должны выполняться под руководством реабилитолога
- При усилении боли или функциональном регрессе необходимо немедленно обратиться к врачу
- Регулярные профессиональные оценки - ключ к успешной реабилитации
- Рекомендации системы носят справочный характер и не заменяют профессиональное суждение

## Анти-паттерны

- **Назначение конкретных упражнений**: система не должна предписывать конкретные реабилитационные упражнения или их параметры (количество повторений, интенсивность)
- **Самостоятельная корректировка фаз**: не следует автоматически переводить пациента на следующую фазу реабилитации без подтверждения реабилитолога
- **Игнорирование сигналов тревоги**: нельзя игнорировать резкое усиление боли, функциональный регресс или признаки осложнений
- **Чрезмерный оптимизм в прогнозах**: не следует занижать прогнозируемое время восстановления для мотивации пациента
- **Замена профессиональной оценки**: система не должна позиционировать свои выводы как замену клинической оценки реабилитолога

## Зависимости

- **Инструменты**: Read, Grep, Glob, Write, Edit
- **Источники данных**: `rehabilitation-tracker.json`, ежедневные журналы реабилитации (`rehabilitation-logs/YYYY-MM/YYYY-MM-DD.json`)
- **Алгоритмы**: линейная регрессия (метод наименьших квадратов), 7-дневное скользящее среднее, линейная экстраполяция, расчёт приверженности
- **Шкалы оценки**: ММТ (мануальное мышечное тестирование), ROM (амплитуда движений), ВАШ/NRS (шкалы боли)
