# Экстренная медицинская карточка -- Описание форматов вывода

## Поддерживаемые форматы вывода

### 0. HTML-формат (рекомендуемый)

**Расширение файла**: `.html`

**Назначение**: печатная, пригодная для передачи веб-страница (наиболее рекомендуемый формат)

**Особенности**:
- Автономный файл (все зависимости через CDN)
- Оптимизация печати (A4, карточка для кошелька, крупный шрифт)
- Адаптивный дизайн
- Tailwind CSS и иконки Lucide
- Автоматическое определение типа карточки
- Работает офлайн (после загрузки)

**Структура данных**:
HTML-файл содержит следующие разделы:
- Заголовок (дата генерации, срок действия, тип карточки)
- Карточка базовой информации (ФИО, возраст, группа крови, вес, рост)
- Раздел тяжёлых аллергий (только 3-4 уровень, красное предупреждение)
- Раздел текущих лекарств (список активных препаратов)
- Раздел медицинских состояний (список хронических заболеваний)
- Раздел имплантатов (при наличии)
- Раздел контактов для экстренной связи
- Отказ от ответственности

**Типы карточек**:
- **Стандартная**: подходит для большинства взрослых
- **Детская**: для лиц до 18 лет, включает информацию о школе
- **Для пожилых**: для лиц старше 65 лет, крупный шрифт, высокая контрастность
- **Для тяжёлых аллергий**: аллергическая информация выделена, включает инструкцию по оказанию первой помощи

**Размеры печати**:
- **A4 стандарт**: полная информация, для печати или архивирования в PDF
- **Карточка для кошелька**: 74 мм x 105 мм, только ключевая информация, для ношения с собой
- **Крупный шрифт**: формат A4, но шрифт 16-18pt, для пожилых людей

**Сценарии использования**:
- Печать для ношения с собой (рекомендуется)
- Сохранение на телефон (работает офлайн)
- Передача врачу (профессиональный вид)
- Долгосрочное хранение (поддерживает поиск)
- Быстрый доступ (печать в один клик)

**Примеры использования**:
```bash
# Генерация HTML-карточки (автоопределение типа)
python scripts/generate_emergency_card.py

# Генерация определённого типа
python scripts/generate_emergency_card.py child

# Генерация карточки для кошелька
python scripts/generate_emergency_card.py standard wallet

# Генерация версии крупным шрифтом
python scripts/generate_emergency_card.py elderly large
```

**Преимущества**:
- Не требуется установка программного обеспечения
- Кроссплатформенная совместимость (Windows, Mac, Linux)
- Прямая печать или сохранение в PDF
- Адаптивный дизайн, читаемый на телефоне
- Профессиональный внешний вид
- Автоматическое скрытие кнопок и рамок при печати

**Технологический стек**:
- Tailwind CSS v3.4 (CDN)
- Lucide Icons v0.263 (CDN)
- Чистый HTML + CSS (без JavaScript-фреймворков)

### 1. JSON-формат

**Расширение файла**: `.json`

**Назначение**: структурированное хранение данных для системной интеграции и программной обработки

**Структура данных**:
```json
{
  "emergency_card": {
    "version": "1.0",
    "generated_at": "2025-12-31T12:34:56Z",
    "expires_at": "2026-03-31T12:34:56Z",
    "basic_info": {
      "name": "Иванов И.И.",
      "age": 35,
      "gender": "муж.",
      "blood_type": "A+",
      "weight": "70 кг",
      "height": "175 см",
      "bmi": 22.9
    },
    "critical_allergies": [...],
    "current_medications": [...],
    "medical_conditions": [...],
    "implants": [...],
    "recent_procedures": [...],
    "recent_radiation_exposure": {...},
    "emergency_contacts": [...],
    "qr_code": "data:image/png;base64,...",
    "disclaimer": "Данная карточка носит справочный характер и не заменяет профессиональную медицинскую диагностику",
    "data_source": "my-his -- персональная система медицинской информации"
  }
}
```

**Описание полей**:
- `version`: номер версии карточки
- `generated_at`: время генерации (формат ISO 8601)
- `expires_at`: срок действия (рекомендуется повторная генерация через 3 месяца)
- `basic_info`: объект базовой информации
- `critical_allergies`: массив тяжёлых аллергий (только 3-4 уровень)
- `current_medications`: массив текущих лекарств (только active=true)
- `medical_conditions`: массив медицинских состояний
- `implants`: массив имплантатов
- `recent_procedures`: массив недавних операций/процедур
- `recent_radiation_exposure`: объект недавнего радиационного облучения
- `emergency_contacts`: массив контактов для экстренной связи
- `qr_code`: изображение QR-кода (кодировка Base64)
- `disclaimer`: отказ от ответственности
- `data_source`: идентификатор источника данных

**Сценарии использования**:
- Резервное копирование в облако
- Миграция данных
- Системная интеграция
- Программная обработка

### 2. Текстовый формат

**Расширение файла**: `.txt`

**Назначение**: легко читаемый и печатаемый, подходит для ношения с собой

**Структура макета**:
```
+==========================================================+
|               ЭКСТРЕННАЯ МЕДИЦИНСКАЯ КАРТОЧКА             |
+==========================================================+
| ФИО: [ФИО]                     Возраст: [возраст] лет    |
| Группа крови: [группа]         Вес: [вес]                |
+==========================================================+
| ТЯЖЁЛЫЕ АЛЛЕРГИИ                                         |
|----------------------------------------------------------|
| * [Аллерген] -- [степень тяжести] ([уровень] уровень)    |
|   Реакция: [описание реакции]                            |
+==========================================================+
| ТЕКУЩИЕ ЛЕКАРСТВА                                        |
|----------------------------------------------------------|
| * [Название] [дозировка] -- [частота], [назначение]      |
+==========================================================+
| МЕДИЦИНСКИЕ СОСТОЯНИЯ                                    |
|----------------------------------------------------------|
| * [Заболевание] (диагноз [дата]) -- [статус]             |
+==========================================================+
| ИМПЛАНТАТЫ (при наличии)                                 |
|----------------------------------------------------------|
| * [Тип имплантата] (установлен [дата])                   |
|   Больница: [название]                                   |
|   Внимание: [примечания]                                 |
+==========================================================+
| КОНТАКТЫ ДЛЯ ЭКСТРЕННОЙ СВЯЗИ                           |
|----------------------------------------------------------|
| * [ФИО] ([отношение]) -- [телефон]                       |
+==========================================================+
| ОТКАЗ ОТ ОТВЕТСТВЕННОСТИ                                 |
| Данная карточка носит справочный характер и не заменяет   |
| профессиональную медицинскую диагностику                  |
| Время генерации: [ГГГГ-ММ-ДД ЧЧ:ММ:СС]                 |
+==========================================================+
```

**Особенности**:
- Символы рамок для структурирования
- Чёткая иерархия
- Подходит для печати (формат A4)

**Рекомендации по печати**:
- **Карточка для кошелька**: уменьшить до 50%, обрезать и положить в кошелёк
- **Для холодильника**: увеличить до 120%, прикрепить на дверцу
- **Карточка для ношения**: уменьшить до 80%, заламинировать для прочности

### 3. Формат QR-кода

**Расширение файла**: `.png`

**Назначение**: быстрый доступ к полной информации при сканировании телефоном

**Способ генерации**:
1. Сжать JSON-данные (опционально)
2. Сгенерировать изображение с помощью библиотеки QR-кодов
3. Сохранить в формате PNG

**Спецификация QR-кода**:
- **Версия**: Version 40 (максимальная ёмкость)
- **Уровень коррекции ошибок**: H (30% коррекция)
- **Размер**: 400x400 пикселей
- **Формат**: PNG

**Содержание данных** (выберите один вариант):

**Вариант 1: Полный JSON**
```
{"emergency_card":{...полный JSON-объект}}
```
- Плюсы: не требуется сеть, прямое декодирование
- Минусы: сложный QR-код, возможны трудности со сканированием

**Вариант 2: Короткая ссылка**
```
https://example.com/emergency/card?id=xxx
```
- Плюсы: простой QR-код, легко сканируется
- Минусы: требуется сеть, зависимость от сервера

**Рекомендация**: используйте Вариант 1 (полный JSON), чтобы обеспечить работу офлайн

**Сценарии использования**:
- Сохранение в галерее телефона
- Жетон на браслете/кулоне
- Обратная сторона карточки для кошелька
- Медицинский браслет

### 4. PDF-формат

**Расширение файла**: `.pdf`

**Назначение**: профессиональная печать, долгосрочное хранение

**Макет страницы**:
- **Размер**: A4 (210x297 мм)
- **Ориентация**: книжная
- **Поля**: 20 мм со всех сторон
- **Шрифт**: заголовок 18pt, основной текст 12pt

**Организация содержания**:
```
Страница 1: Сводка экстренной информации
|- Заголовок и дата генерации
|- Карточка базовой информации
|- Предупреждения о тяжёлых аллергиях
|- Список текущих лекарств
|- Список медицинских состояний
|- Контакты для экстренной связи

Страница 2 (при необходимости): Подробная информация
|- Информация об имплантатах
|- Недавние хирургические записи
|- Недавнее радиационное облучение
|- Предупреждения о лекарственных взаимодействиях
|- Указания при обращении к врачу
```

**Характеристики PDF**:
- Поддержка кириллицы
- Поддержка копирования и вставки
- Поддержка поиска
- Защита от редактирования (защита информации)

**Сценарии использования**:
- Печать для врача при визите
- Архивирование в больнице
- Документы для визы при путешествии
- Страховые выплаты

## Руководство по выбору формата

### По сценарию использования

| Сценарий | Рекомендуемый формат | Запасной формат |
|----------|---------------------|-----------------|
| **Сохранение на телефон** | QR-код (PNG) | JSON |
| **Ношение с собой** | Текст (уменьшенная печать) | QR-код |
| **Холодильник/дверь** | Текст (увеличенная печать) | -- |
| **Подготовка к поездке** | QR-код + текст | JSON |
| **Подготовка к визиту к врачу** | PDF | Текст |
| **Резервное копирование в облако** | JSON | PDF |
| **Миграция данных** | JSON | -- |
| **Передача врачу** | PDF | Текст |
| **Экстренная ситуация** | QR-код + текст | -- |

### По устройству

| Устройство | Рекомендуемый формат | Причина |
|------------|---------------------|---------|
| **Смартфон** | QR-код (PNG) | Быстрое сканирование, полная информация |
| **Кнопочный телефон** | Текст (TXT) | Без сканирования, прямое чтение |
| **Планшет** | PDF | Хорошее чтение |
| **Компьютер** | JSON/PDF | Удобство обработки и печати |
| **Бумага** | Текст/PDF | Чёткость и читаемость |

## Специальные варианты форматов

### Детский формат

**Особенности**:
- Информация о школе и классе
- Приоритет контактов родителей
- Контакт медкабинета школы
- Указания для учителей

```json
{
  "basic_info": {
    "name": "Петров М.А.",
    "age": 8,
    "school": "Школа N 15",
    "grade": "2 класс",
    "class": "2-Б"
  },
  "school_contacts": [
    {"role": "Классный руководитель", "name": "Смирнова О.В.", "phone": "+7 (9**) ***-**-34"},
    {"role": "Школьный врач", "name": "Кузнецова Т.И.", "phone": "+7 (4**) ***-**-78"}
  ],
  "school_instructions": [...]
}
```

### Формат для пожилых

**Особенности**:
- Крупный шрифт (18-20pt)
- Высококонтрастные цвета
- Пометка об одиноком проживании
- Контакт участкового врача
- Контакт соседей

### Формат для тяжёлых аллергий

**Особенности**:
- Аллергическая информация вверху, выделена жирным
- Предупреждения о перекрёстных аллергиях
- Подробный алгоритм оказания первой помощи при аллергии
- Список противопоказанных лекарств

## Правила именования файлов

### Стандартное именование
```
emergency-card-ГГГГ-ММ-ДД.{расширение}
```
Примеры:
- `emergency-card-2025-12-31.json`
- `emergency-card-2025-12-31.txt`
- `emergency-card-2025-12-31.png`
- `emergency-card-2025-12-31.pdf`

### Специальное именование

**Детская**:
```
emergency-card-child-{имя}-ГГГГ-ММ-ДД.{расширение}
```

**Для пожилых**:
```
emergency-card-elderly-{имя}-ГГГГ-ММ-ДД.{расширение}
```

**Для тяжёлых аллергий**:
```
emergency-card-allergy-{имя}-ГГГГ-ММ-ДД.{расширение}
```
