# Экстренная медицинская карточка -- Примеры использования

## Пример 1: Подготовка экстренной карточки к путешествию

### Ввод пользователя
```
На следующей неделе я еду в Москву, нужно подготовить экстренную медицинскую карточку
```

### Действия Claude
1. Чтение истории аллергий пользователя (обнаружена аллергия на пенициллин 4 уровня)
2. Чтение текущих лекарств (аспирин, амлодипин)
3. Чтение информации об имплантатах (кардиостимулятор)
4. Генерация карточки с ключевой информацией в форматах JSON и текст
5. Генерация QR-кода для сканирования телефоном

### Результат

    "generated_at": "2025-12-31T12:34:56Z",
    "basic_info": {

      "age": 35,
      "gender": "муж.",
      "blood_type": "A+",
      "weight": "70 кг",
      "emergency_contacts": [
        {
          "name": "Петрова А.В.",
          "relationship": "супруга",
          "phone": "+7 (9**) ***-**-34"
        }
      ]
    },
    "critical_allergies": [
      {
        "allergen": "Пенициллин",
        "severity": "Анафилактический шок (4 уровень)",

        "diagnosed_date": "2010-05-15"

    ],
    "current_medications": [
      {
        "name": "Аспирин",

      },

        "name": "Амлодипин",

      {
        "condition": "Гипертония",

```

### Рекомендации для путешествия
```
Рекомендации:
-------------------------------
1. Сохраните QR-код в галерею телефона
2. Распечатайте текстовую версию и положите в кошелёк
3. Загрузите JSON-файл в облачное хранилище
4. Носите с собой карточку экстренной помощи при аллергиях
5. Сообщите попутчикам о ваших аллергиях

Особое внимание:
-------------------------------
* Кардиостимулятор: предупредите при прохождении контроля в аэропорту
* Аллергия на пенициллин: обязательно сообщите врачу при обращении
* Лекарства для хронических заболеваний: возьмите достаточный запас и разделите на части
```

## Пример 2: Карточка экстренной помощи для пожилого человека

### Ввод пользователя
```
Моему отцу 75 лет, живёт один, нужна карточка экстренной помощи
```

### Действия Claude
1. Чтение профиля отца пользователя (возраст: 75 лет, группа крови: B+)
2. Чтение истории тяжёлых аллергий (сульфаниламиды, 3 уровень)
3. Чтение множественных лекарств (5 препаратов для хронических заболеваний)
4. Чтение медицинских состояний (гипертония, диабет, ИБС)
5. Генерация карточки с крупным шрифтом

### Результат (текстовый формат)
```
+==========================================================+
|             КАРТОЧКА ЭКСТРЕННОЙ ПОМОЩИ (ПОЖИЛОЙ)         |
+==========================================================+
| ФИО: Сидоров П.А.              Возраст: 75 лет          |
| Пол: муж.                      Группа крови: B+          |
+==========================================================+
| ТЯЖЁЛЫЕ АЛЛЕРГИИ (ЭКСТРЕННО)                            |
|----------------------------------------------------------|
| * Сульфаниламиды -- тяжёлая аллергия (3 уровень)        |
|   Реакция: распространённая сыпь, лихорадка             |
+==========================================================+
| ТЕКУЩИЕ ЛЕКАРСТВА (5 препаратов)                         |
|----------------------------------------------------------|
| 1. Аспирин 100 мг -- 1 раз/день                         |
| 2. Амлодипин 5 мг -- 2 раза/день                        |
| 3. Метформин 500 мг -- 3 раза/день                      |
| 4. Метопролол 25 мг -- 2 раза/день                      |
| 5. Симвастатин 20 мг -- 1 раз/вечер                     |
+==========================================================+
| МЕДИЦИНСКИЕ СОСТОЯНИЯ                                    |
|----------------------------------------------------------|
| * Гипертония (диагноз 2018-03-10)                       |
| * СД 2 типа (диагноз 2019-07-22)                        |
| * ИБС (диагноз 2020-11-05)                              |
+==========================================================+
| КОНТАКТЫ ДЛЯ ЭКСТРЕННОЙ СВЯЗИ (2 чел.)                  |
|----------------------------------------------------------|
| 1. Сидоров А.П. (сын) -- +7 (9**) ***-**-78             |
| 2. Сидорова Е.В. (невестка) -- +7 (9**) ***-**-12       |
+==========================================================+
| ОСОБОЕ ВНИМАНИЕ                                          |
|----------------------------------------------------------|
| * Одинокий пожилой человек -- сначала свяжитесь с        |
|   родственниками                                         |
| * Тяжёлая аллергия на сульфаниламиды -- абсолютно        |
|   противопоказаны                                        |
| * Сердечно-сосудистые заболевания в анамнезе --           |
|   контроль АД и ЧСС                                     |
+==========================================================+

При экстренной ситуации немедленно вызовите скорую помощь: 103 / 112
Время генерации: 2025-12-31 12:34:56
```

### Рекомендации для пожилых
```
Рекомендации:
-------------------------------
1. Распечатайте карточку крупным шрифтом и прикрепите на холодильник
2. Носите с собой карточку малого формата
3. Сообщите соседям и участковому врачу
4. Настройте быстрый набор экстренных контактов на телефоне
5. Обновляйте информацию каждые 3 месяца
```

## Пример 4: Здоровый человек без аллергий и лекарств

### Ввод пользователя
```
Сгенерировать экстренную медицинскую карточку
```

### Действия Claude
1. Чтение профиля пользователя (возраст: 28 лет, здоров)
2. Аллергии не обнаружены
3. Текущие лекарства не обнаружены
4. Имплантаты не обнаружены
5. Генерация базовой информационной карточки

### Результат
```
Экстренная медицинская карточка успешно сгенерирована

Расположение файла: data/emergency-cards/emergency-card-2025-12-31.json

Включённая информация:
-------------------------------
- Базовая информация (ФИО, возраст, группа крови)
- История аллергий: не зафиксирована
- Текущие лекарства: нет
- Медицинские состояния: нет
- Имплантаты: нет

Пояснение:
-------------------------------
У вас не зафиксировано тяжёлых аллергий, лекарств или медицинских состояний.
Рекомендации:
* Регулярно обновляйте медицинскую информацию
* При появлении новых диагнозов своевременно вносите записи
* Перед поездкой сгенерируйте актуальную карточку
```

## Пример 5: Множественные тяжёлые аллергии + множественные лекарства

```

## Сводка типичных сценариев использования

| Сценарий | Ключевая информация | Рекомендуемый формат |
|----------|---------------------|---------------------|
| **Путешествие** | Аллергии, лекарства, имплантаты | QR-код + текст |
| **Одинокий пожилой** | Множественные лекарства, экстренные контакты | Текст крупным шрифтом |
| **Ребёнок в школе** | Аллергии, контакты родителей | Формат для школы |
| **Тяжёлые аллергии** | Аллергены, перекрёстные аллергии, алгоритм помощи | Подробная версия + инструкция |
| **Подготовка к операции** | Лекарства, имплантаты, аллергии | Формат для врача |
| **Повседневное ношение** | Краткая ключевая информация | Размер карточки для кошелька |
