# Навык анализа питания

## Обзор

Навык анализа питания предназначен для комплексной оценки рациона пользователя: анализ трендов потребления нутриентов, выявление пищевых паттернов и дефицитов, а также генерация персонализированных рекомендаций. Поддерживает корреляционный анализ питания с показателями физической активности, сна, артериального давления и уровня глюкозы.

## Зависимости

- **Read, Grep, Glob, Write** — инструменты для чтения, поиска и записи файлов данных
- **data-example/nutrition-tracker.json** — основной источник данных отслеживания питания
- **data-example/nutrition-logs/** — ежедневные записи рациона в формате JSON
- **data-example/profile.json** — профиль пользователя (вес, ИМТ, цели)
- **data-example/fitness-tracker.json, sleep-tracker.json, hypertension-tracker.json, diabetes-tracker.json** — связанные источники данных для корреляционного анализа
- **Стандарты DRIs/RDA** — справочные нормы потребления нутриентов

## Интеграция с другими скиллами

- При обнаружении лекарственных взаимодействий с продуктами → использовать tooluniverse-drug-drug-interaction
- Результаты анализов крови (lab-results) используются для определения дефицитов нутриентов
- Данные о тренировках (fitness-analyzer) влияют на расчёт потребности в калориях и макронутриентах

## Функции

### 1. Анализ трендов питания

Анализ тенденций потребления нутриентов, выявление улучшений или областей, требующих внимания.

**Аналитические измерения**:
- Тренды макронутриентов (белки, углеводы, жиры, клетчатка, калории)
- Тренды микронутриентов (витамины, минералы)
- Изменения в распределении источников калорий
- Паттерны приёма пищи (время, частота)
- Предпочтения по категориям продуктов

**Выходные данные**:
- Направление тренда (улучшение/стабильность/снижение)
- Величина изменения и проценты
- Значимость тренда
- Рекомендации по улучшению

### 2. Оценка потребления нутриентов

Оценка соответствия потребления нутриентов рекомендуемым нормам (RDA/AI).

**Содержание оценки**:
- **Оценка макронутриентов**:
  - Количество и качество потребления белка
  - Распределение типов углеводов (рафинированные vs сложные углеводы)
  - Распределение типов жиров (насыщенные/мононенасыщенные/полиненасыщенные/трансжиры)
  - Потребление пищевых волокон

- **Оценка витаминов**:
  - Витамины A, C, D, E, K
  - Витамины группы B (B1, B2, B3, B6, B12, фолиевая кислота, пантотеновая кислота, биотин)
  - Сравнение с RDA
  - Оценка риска дефицита

- **Оценка минералов**:
  - Макроминералы: кальций, фосфор, магний, натрий, калий, хлор, сера
  - Микроминералы: железо, цинк, медь, марганец, йод, селен, хром, молибден
  - Сравнение с RDA
  - Оценка риска дефицита

- **Оценка специальных нутриентов**:
  - Omega-3 жирные кислоты (EPA, DHA, ALA)
  - Холин
  - Коэнзим Q10
  - Фитохимические вещества (флавоноиды, каротиноиды и др.)

**Выходные данные**:
- Процент достижения нормы по каждому нутриенту
- Градация: дефицит/недостаточность/достаточность/избыток
- Выявление рисков дефицита
- Приоритетные рекомендации по улучшению

### 3. Оценка нутритивного статуса

Комплексная оценка нутритивного статуса пользователя.

**Содержание оценки**:
- **Общая оценка качества питания**:
  - Оценка нутриентной плотности
  - Оценка разнообразия рациона
  - Оценка сбалансированности питания

- **Определение пищевых паттернов**:
  - Тип диеты (средиземноморская, DASH, вегетарианская и др.)
  - Паттерн времени приёма пищи (частота, окно приёма пищи)
  - Паттерны перекусов и дополнительных приёмов пищи

- **Определение нутритивных рисков**:
  - Риск дефицита нутриентов (например, дефицит витамина D, дефицит железа)
  - Риск избытка нутриентов (например, избыток витамина A, избыток натрия)
  - Нездоровые пищевые привычки (высокое содержание сахара, жиров, натрия)

**Выходные данные**:
- Уровень нутритивного статуса (отлично/хорошо/удовлетворительно/неудовлетворительно)
- Выявление основных нутритивных проблем
- Список факторов риска
- Приоритеты улучшения

### 4. Корреляционный анализ

Анализ взаимосвязей между питанием и другими показателями здоровья.

**Поддерживаемые виды корреляционного анализа**:
- **Питание ↔ Вес**:
  - Связь калорийности рациона с изменением веса
  - Соотношение макронутриентов и управление весом
  - Связь времени приёма пищи с метаболизмом

- **Питание ↔ Физическая активность**:
  - Влияние потребления нутриентов на спортивные результаты
  - Потребности в питании в дни тренировок vs дни отдыха
  - Потребление белка и восстановление мышц

- **Питание ↔ Сон**:
  - Потребление кофеина и качество сна
  - Время ужина и время засыпания
  - Определённые нутриенты (магний, триптофан) и сон

- **Питание ↔ Артериальное давление**:
  - Потребление натрия и артериальное давление
  - Соотношение калий/натрий и артериальное давление
  - Приверженность диете DASH и контроль артериального давления

- **Питание ↔ Уровень глюкозы**:
  - Типы углеводов и колебания глюкозы крови
  - Пищевые волокна и контроль глюкозы
  - Время приёма пищи и гликемическая кривая

**Выходные данные**:
- Коэффициент корреляции (от -1 до 1)
- Сила корреляции (слабая/средняя/сильная)
- Статистическая значимость
- Выводы о причинно-следственных связях
- Практические рекомендации

### 5. Генерация персонализированных рекомендаций

Генерация персонализированных рекомендаций по улучшению питания на основе данных пользователя.

**Типы рекомендаций**:
- **Рекомендации по коррекции нутриентов**:
  - Увеличение потребления дефицитных нутриентов
  - Снижение потребления избыточных нутриентов
  - Оптимизация соотношения нутриентов

- **Рекомендации по выбору продуктов**:
  - Рекомендация определённых категорий продуктов
  - Замена продуктов (более здоровые альтернативы)
  - Сочетание продуктов (для улучшения усвоения)

- **Рекомендации по пищевым привычкам**:
  - Корректировка времени приёма пищи
  - Корректировка частоты приёма пищи
  - Рекомендации по способам приготовления

- **Рекомендации по добавкам** (только для справки):
  - Рекомендации по добавкам на основе рисков дефицита
  - Дозировка и время приёма добавок
  - Предупреждения о взаимодействиях

**Основания для рекомендаций**:
- Стандарты DRIs/RDA
- Исторические данные о питании пользователя
- Состояние здоровья и цели пользователя
- Доказательная нутрициология

## Инструкция по использованию

### Условия активации

Данный навык активируется при запросе пользователем следующей информации:
- Анализ трендов питания
- Оценка потребления нутриентов
- Оценка нутритивного статуса
- Рекомендации по улучшению питания
- Корреляционный анализ питания с другими показателями здоровья

### Порядок выполнения

#### Шаг 1: Определение объёма анализа

Уточнение типа анализа и временного диапазона запроса пользователя:
- Тип анализа: тренды/оценка/корреляция/рекомендации
- Временной диапазон: неделя/месяц/квартал/пользовательский
- Глубина анализа: макронутриенты/микронутриенты/полный анализ

#### Шаг 2: Чтение данных

**Основные источники данных**:
1. `data-example/nutrition-tracker.json` - Основные данные отслеживания питания
2. `data-example/nutrition-logs/YYYY-MM/YYYY-MM-DD.json` - Ежедневные записи рациона

**Связанные источники данных**:
1. `data-example/profile.json` - Вес, ИМТ и другие базовые данные
2. `data-example/fitness-tracker.json` - Данные о физической активности
3. `data-example/sleep-tracker.json` - Данные о сне
4. `data-example/hypertension-tracker.json` - Данные об артериальном давлении
5. `data-example/diabetes-tracker.json` - Данные об уровне глюкозы

#### Шаг 3: Анализ данных

Выполнение соответствующего алгоритма анализа в зависимости от типа анализа:

**Алгоритм анализа трендов**:
- Линейная регрессия для расчёта наклона тренда
- Скользящее среднее для сглаживания колебаний
- Проверка статистической значимости

**Расчёт достижения RDA**:
```python
rda_achievement = (actual_intake / rda_value) * 100

status_classification:
- < 50%: Тяжёлый дефицит
- 50-75%: Недостаточность
- 75-100%: Приближение к цели
- 100-150%: Достаточность (идеальный диапазон)
- > 150%: Избыток (обратите внимание на безопасный верхний предел UL)
```

**Оценка нутриентной плотности**:
```python
nutrient_density_score = (
    (vitamins_achieved / total_vitamins) * 40 +
    (minerals_achieved / total_minerals) * 30 +
    (fiber_achieved / fiber_rda) * 30
)
```

**Алгоритм корреляционного анализа**:
- Расчёт коэффициента корреляции Pearson
- Анализ запаздывающей корреляции (с учётом эффекта временной задержки)
- Множественный регрессионный анализ

#### Шаг 4: Формирование отчёта

Вывод аналитического отчёта в стандартном формате (см. раздел «Формат вывода»)

## Описание алгоритмов

### Расчёт достижения RDA

```python
def calculate_rda_achievement(actual_intake, rda_value, ul_value=None):
    """
    Расчёт процента достижения RDA и статуса

    Параметры:
    - actual_intake: Фактическое потребление
    - rda_value: Рекомендуемая норма потребления
    - ul_value: Допустимый верхний уровень потребления (необязательно)

    Возвращает:
    - achievement_rate: Процент достижения
    - status: Метка статуса
    """
    achievement_rate = (actual_intake / rda_value) * 100

    if ul_value and actual_intake > ul_value:
        status = "exceeds_ul"
        category = "Избыток (опасно)"
    elif achievement_rate < 50:
        status = "severe_deficiency"
        category = "Тяжёлый дефицит"
    elif achievement_rate < 75:
        status = "insufficient"
        category = "Недостаточность"
    elif achievement_rate < 100:
        status = "approaching_target"
        category = "Приближение к цели"
    elif achievement_rate <= 150:
        status = "adequate"
        category = "Достаточно"
    else:
        status = "high_intake"
        category = "Повышенное"

    return {
        'achievement_rate': round(achievement_rate, 1),
        'status': status,
        'category': category
    }
```

### Оценка нутриентной плотности

```python
def calculate_nutrient_density_score(meal_data):
    """
    Расчёт оценки нутриентной плотности продуктов (0-10 баллов)

    Весовые коэффициенты:
    - Достижение по витаминам: 40%
    - Достижение по минералам: 30%
    - Пищевые волокна: 20%
    - Ограничительные нутриенты (насыщенные жиры, натрий, добавленный сахар): 10%
    """
    score = 0

    # Оценка по витаминам
    vitamin_achievements = [
        meal_data['micronutrients'][v] / RDA[v]
        for v in ['vitamin_a', 'vitamin_c', 'vitamin_d', 'vitamin_e', 'vitamin_k']
    ]
    vitamin_score = min(sum(vitamin_achievements) / len(vitamin_achievements), 1.5) * 10
    score += min(vitamin_score, 10) * 0.40

    # Оценка по минералам
    mineral_achievements = [
        meal_data['micronutrients'][m] / RDA[m]
        for m in ['calcium', 'iron', 'magnesium', 'zinc']
    ]
    mineral_score = min(sum(mineral_achievements) / len(mineral_achievements), 1.5) * 10
    score += min(mineral_score, 10) * 0.30

    # Оценка по пищевым волокнам
    fiber_score = min(meal_data['macronutrients']['fiber_g'] / 5, 2) * 10
    score += min(fiber_score, 10) * 0.20

    # Штраф за ограничительные нутриенты
    penalty = 0
    if meal_data['macronutrients']['saturated_fat_g'] > 10:
        penalty += 2
    if meal_data['micronutrients']['sodium_mg'] > 600:
        penalty += 2
    if meal_data.get('added_sugars_g', 0) > 10:
        penalty += 2

    score = max(0, score - penalty * 0.10)

    return round(score, 1)
```

### Индекс здорового питания

```python
def calculate_healthy_eating_index(daily_data):
    """
    Расчёт индекса здорового питания (адаптация HEI-2015)

    Диапазон оценки: 0-100 баллов
    """
    score = 0

    # Компоненты достаточности (максимум 50 баллов)
    # 1. Фрукты (5 баллов)
    fruit_servings = daily_data['fruit_servings']
    score += min(fruit_servings, 2.5) * 2

    # 2. Овощи (5 баллов)
    veg_servings = daily_data['vegetable_servings']
    score += min(veg_servings, 3) * 1.67

    # 3. Цельнозерновые (10 баллов)
    whole_grains_oz = daily_data['whole_grains_oz']
    score += min(whole_grains_oz, 3) * 3.33

    # 4. Молочные продукты (10 баллов)
    dairy_servings = daily_data['dairy_servings']
    score += min(dairy_servings, 3) * 3.33

    # 5. Белок (5 баллов)
    protein_oz = daily_data['protein_oz']
    score += min(protein_oz, 5) * 1

    # 6. Морепродукты/растительный белок (5 баллов)
    plant_protein_oz = daily_data['plant_protein_oz']
    score += min(plant_protein_oz, 2) * 2.5

    # 7. Соотношение жирных кислот (10 баллов)
    fat_ratio = daily_data['unsaturated_fat_g'] / max(daily_data['saturated_fat_g'], 1)
    score += min(fat_ratio, 2.5) * 4

    # Компоненты умеренности (максимум 40 баллов, обратная оценка)
    # 8. Рафинированные злаки (10 баллов, чем меньше, тем лучше)
    refined_grains_oz = daily_data['refined_grains_oz']
    score += max(10 - refined_grains_oz * 2, 0)

    # 9. Натрий (10 баллов, чем меньше, тем лучше)
    sodium_g = daily_data['sodium_mg'] / 1000
    score += max(10 - sodium_g * 2, 0)

    # 10. Добавленный сахар (10 баллов, чем меньше, тем лучше)
    added_sugars_pct = daily_data['added_sugars_g'] / (daily_data['total_calories'] / 100)
    score += max(10 - added_sugars_pct * 10, 0)

    # 11. Насыщенные жиры (10 баллов, чем меньше, тем лучше)
    saturated_fat_pct = daily_data['saturated_fat_g'] / (daily_data['total_calories'] / 100)
    score += max(10 - saturated_fat_pct * 10, 0)

    return round(score, 1)
```
