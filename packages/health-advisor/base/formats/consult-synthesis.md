# Render contract — синтез консилиума (сборщик → synthesis.md)

Контракт терапевта-СБОРЩИКА. Сборщик НЕ пересказывает: он ТРАНСКЛЮДИРУЕТ якорные блоки по
`finding_id` и не имеет права переписать ни одно число и ни один вердикт. Документ проверяется
машинным гейтом (`consult-gate`); всё, что не по контракту, — нарушение с кодом.

## Словарь якорей

```markdown
<!-- ha:finding id="<finding_id>" severity="<severity>" -->
  текст утверждения (claim) — дословно из lane-файла
  <!-- ha:value ref="qv1" value="4.9" unit="ммоль/л" -->4.9 ммоль/л<!-- /ha:value -->
  <!-- ha:caveat id="<caveat_id>" applies-to="claim,dose1,pop1" -->текст оговорки дословно<!-- /ha:caveat -->
<!-- /ha:finding -->

<!-- ha:not-carried id="<finding_id>" reason="<enum>" note="свободный ХВОСТ, не замена кода" -->
<!-- ha:lane-failed specialty="<specialty>" reason="<reason>" -->

<!-- ha:ungated -->
этот раздел написан моделью и НЕ проверяется гейтом
…свободный текст…
<!-- /ha:ungated -->
```

## Правила (каждое = ось гейта)

1. **Связка, не текст** (INV-5): `applies-to` оговорки должен МНОЖЕСТВОМ совпадать с
   `applies_to` источника. Оговорка под чужим `finding_id` или с суженным applies-to — MISS,
   даже при дословном тексте.
2. **Байт-совпадение значений**: каждый `ha:value` совпадает с `quoted_values` источника —
   `value` И `unit`, без округления. Каждое `quoted_value` транслюдированной находки обязано быть
   отрендерено якорем; голое число вне `ha:value` — `UNANCHORED_NUMBER` («числа перечитывать,
   а не пересказывать»).
3. **Покрытие**: каждая находка severity ≥ moderate либо транслюдирована, либо в «Не перенесено»
   с ENUM-кодом причины: `duplicate_of:<id>` | `superseded_by:<id>` | `out_of_scope_of_complaint`
   | `lane_failed`. Свободный текст — только ДОБАВКОЙ в `note`.
4. **Провенанс**: `ASSERTED` в готовом документе запрещён.
5. **Упавшие специалисты раскрываются**: каждому `LaneFailure` — `ha:lane-failed` в документе.
6. **Ровно ОДНА свободная секция** — «Межспециальные взаимодействия», внутри `ha:ungated`:
   - открывается видимой меткой: «этот раздел написан моделью и НЕ проверяется гейтом»;
   - может СОПОСТАВЛЯТЬ находки и ПОКАЗЫВАТЬ противоречия, но не разрешать их;
   - каждый процитированный `finding_id` везёт СВОИ material-оговорки якорями прямо в секции
     (правило связки распространяется на цитаты в тексте — AM-2);
   - голых чисел внутри нет.
7. **Фехтованный код — не якорное пространство**: якорь внутри ``` не считается (в обе стороны).
