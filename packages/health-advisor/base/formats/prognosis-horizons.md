# Формат: прогностические горизонты (lifespan / healthspan)

Один и тот же вопрос «сколько?» имеет два разных горизонта, и ответ, выданный по неверному
горизонту, отвечает не на тот вопрос, который был задан, — при этом выглядит как ответ.

## Определения

- **Lifespan (продолжительность жизни)** — ожидаемый срок жизни.
- **Healthspan (срок сохранной дееспособности)** — ожидаемый срок, в течение которого человек
  сохраняет самостоятельность и способность к активности, ради которой задан вопрос.

## Обязательный блок каждого прогностического утверждения

Любое прогностическое утверждение (риск, долголетие, «сколько ещё смогу…») эмитится этим блоком,
с маркером для машинной проверки:

<!-- ha:prognosis-horizons -->
| Горизонт | Оценка | Диапазон | На чём основано |
|---|---|---|---|
| Продолжительность жизни (lifespan) | … | … | … |
| Срок сохранной дееспособности (healthspan) | … | … | … |

**Ваша цель:** «…» → этот срок определяется горизонтом **healthspan**, а не lifespan.
**Погрешность:** обе величины — популяционные оценки, применённые к одному человеку; они не являются
предсказанием вашей судьбы и требуют обсуждения с врачом.

## Правила заполнения (обязательные)

- Ни одна ячейка не может быть голым числом: требуется **оценка + Диапазон + На чём основано** —
  все три. Где основания нет, ячейка читается `недостаточно данных` — это валидный и ожидаемый
  ответ, а не провал, который надо замазать.
- Строка **Ваша цель:** цитирует заявленную цель пациента **его собственными словами** и называет,
  какой горизонт ею управляет.
- Пакет НЕ выдаёт числовых значений сам: правило «Не оценивать прогноз жизни»
  (health-trend-analyzer) действует. Блок структурирует то, что пациент обсуждает с врачом,
  а не вычисляет прогноз.

## Иллюстративный случай (пример ОДНОГО пациента, не значение по умолчанию)

У пациента, чей вопрос породил этот формат, цель была «помогать с внуками». В его —
иллюстративном, единичном — случае врачебное обсуждение развело горизонты примерно на 8–10 лет:
сохранная дееспособность оценивалась серединой-концом седьмого десятка, продолжительность жизни —
серединой девятого. Эти числа — случай одного человека, приведённый как пример заполнения таблицы;
они никогда не подставляются по умолчанию.

*Не является медицинской рекомендацией — обсудите с лечащим врачом.*
