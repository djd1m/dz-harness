# Module 7: Special Practices Analysis

## Purpose
Research evidence for specific health practices the patient uses or considers — fasting, supplementation protocols, alternative therapies, etc.

## Common Practices to Analyze
- Water fasting (prolonged, 3-7 days)
- Intermittent fasting (16:8, 36h, alternate-day)
- Fasting-mimicking diet (FMD / ProLon)
- Combined fasting + exercise (fasted hiking, etc.)
- Cold exposure (ice baths, cold showers)
- Sauna / heat therapy
- Meditation / stress management
- Specific supplement protocols

## For Each Practice, Research:
1. Evidence base (RCTs, meta-analyses)
2. Effect on EACH of the patient's conditions
3. Risks specific to the patient's profile
4. Optimal protocol (frequency, duration, intensity)
5. Integration with existing treatment and exercise program
6. Safety checklist
7. Contraindications
8. Verdict: beneficial / neutral / potentially harmful

## Output
- Individual research file per practice
- Clear verdict with risk-benefit table
- Integration notes with exercise program (Module 5) and nutrition (Module 6)
