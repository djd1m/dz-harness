# Module 8: Monitoring Plan

## Purpose
Create a schedule of follow-up tests, target values, and red flags for the patient.

## Depends On
- Module 1 (Profile) — what to monitor
- Module 2 (Medications) — drug-specific monitoring

## Output Structure

### Monitoring Schedule
| Timeframe | Tests | Purpose | Target Values |
|---|---|---|---|

### Target Values Table
| Parameter | Current | Target | Timeline | How to Achieve |
|---|---|---|---|---|

### Red Flags (seek immediate medical attention)
- List of symptoms/values that require urgent action

### Progress Tracking Template
Simple table the patient fills in at each test to track trends.
