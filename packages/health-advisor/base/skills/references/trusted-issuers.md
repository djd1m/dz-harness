# Trusted Issuer Whitelist for Medical Research

> Reference file for health-advisor-research.md. Defines which sources are trusted for medical claims.

## Tier 1 — Gold (Trust Level 5)

Primary evidence sources. Claims from these sources require no additional verification.

| Domain | Name | Type |
|---|---|---|
| pubmed.ncbi.nlm.nih.gov | PubMed / MEDLINE | Primary research database |
| cochranelibrary.com | Cochrane Library | Systematic reviews |
| who.int | World Health Organization | Global guidelines |
| escardio.org | European Society of Cardiology | CV guidelines |
| heart.org | American Heart Association | CV guidelines |
| acsm.org | American College of Sports Medicine | Exercise guidelines |
| endocrine.org | Endocrine Society | Endocrine guidelines |
| kidney.org | National Kidney Foundation (KDIGO) | Renal guidelines |
| diabetesjournals.org | American Diabetes Association | Diabetes guidelines |

## Tier 2 — Silver (Trust Level 4)

High-quality journals. Claims require at least one Tier 1 cross-reference.

| Domain | Name | Type |
|---|---|---|
| nejm.org | New England Journal of Medicine | Journal |
| thelancet.com | The Lancet | Journal |
| jamanetwork.com | JAMA Network | Journal |
| ahajournals.org | AHA Journals (Circulation, Stroke) | Journal |
| bmj.com | BMJ | Journal |
| nature.com | Nature / Nature Medicine | Journal |
| ods.od.nih.gov | NIH Office of Dietary Supplements | Reference |
| rae-org.ru | Российская ассоциация эндокринологов | National guidelines (RU) |
| scardio.ru | Российское кардиологическое общество | National guidelines (RU) |
| grls.rosminzdrav.ru | ГРЛС (Гос. реестр лекарственных средств) | Drug registry (RU) |

## Tier 3 — Bronze (Trust Level 3)

Reference sources. Cannot be sole source for a recommendation.

| Domain | Name | Type |
|---|---|---|
| ncbi.nlm.nih.gov/books | StatPearls / NCBI Bookshelf | Textbook reference |
| uptodate.com | UpToDate | Secondary review |
| rlsnet.ru | РЛС (Реестр лекарственных средств) | Drug reference (RU) |
| vidal.ru | Видаль | Drug reference (RU) |

## Untrusted (Trust Level 0)

Never use as sole source. May cite for context only, with explicit caveat.

| Domain | Reason |
|---|---|
| wikipedia.org | User-editable, not peer-reviewed |
| webmd.com | Consumer-oriented, oversimplified |
| healthline.com | Consumer-oriented, sponsored content |
| mayoclinic.org | Acceptable for patient education, not for evidence |
| zen.yandex.ru | Unverified blog posts |
| pikabu.ru | Social media |
