# Emergency Thresholds — Critical Lab Values

> Reference file for health-advisor.md Emergency Protocol.
> Sources: WHO, AHA, ESC, KDIGO critical value guidelines.

## Immediate Emergency (СКОРАЯ ПОМОЩЬ 103/112)

| Parameter | Critical Low | Critical High | Clinical Significance | Source |
|---|---|---|---|---|
| Калий (K+) | <3.0 ммоль/л | >6.0 ммоль/л | Аритмия, остановка сердца | [AHA ACLS Guidelines](https://pubmed.ncbi.nlm.nih.gov/33081529/) |
| Глюкоза | <3.0 ммоль/л | >20.0 ммоль/л | Гипогликемическая/гипергликемическая кома | [ADA Standards of Care](https://diabetesjournals.org/care/article/47/Supplement_1/S77/153942/) |
| Натрий (Na+) | <120 ммоль/л | >160 ммоль/л | Отёк мозга / судороги | [Spasovski et al., Eur J Endocrinol 2014](https://pubmed.ncbi.nlm.nih.gov/24569125/) |
| Гемоглобин (Hb) | <70 г/л | — | Тяжёлая анемия, показание к трансфузии | [WHO Haemoglobin Guidelines](https://www.who.int/publications/i/item/9789241548065) |
| Тропонин I/T | — | >0.04 нг/мл (>99-й перцентиль) | Подозрение на инфаркт миокарда | [Thygesen et al., Fourth Universal Definition of MI, ESC 2018](https://pubmed.ncbi.nlm.nih.gov/30153967/) |
| Лактат | — | >4.0 ммоль/л | Шок / сепсис / тяжёлая гипоперфузия | [Surviving Sepsis Campaign 2021](https://pubmed.ncbi.nlm.nih.gov/34599691/) |

| Parameter | Critical Value | Clinical Significance | Source |
|---|---|---|---|
| D-димер | >500 нг/мл | Подозрение на ТЭЛА/ТГВ | [Wells Score + D-dimer, NEJM 2003](https://pubmed.ncbi.nlm.nih.gov/14507948/) |
| Тромбоциты | <50 x10⁹/л | Риск спонтанного кровотечения | [ASH Thrombocytopenia Guidelines](https://pubmed.ncbi.nlm.nih.gov/31461778/) |
| Креатинин | >350 мкмоль/л | Острая почечная недостаточность | [KDIGO AKI Guideline 2012](https://pubmed.ncbi.nlm.nih.gov/22890468/) |
| АЛТ/АСТ | >500 Ед/л (>10x ULN) | Острое повреждение печени | [EASL CPG Drug-Induced Liver Injury 2019](https://pubmed.ncbi.nlm.nih.gov/30926241/) |
| ТТГ | <0.01 или >50 мМЕ/л | Тиреотоксический криз / микседематозная кома | [ATA Thyroid Storm Guidelines 2016](https://pubmed.ncbi.nlm.nih.gov/27521067/) |
| Кальций | <1.8 или >3.5 ммоль/л | Гипо/гиперкальциемический криз | [Endocrine Society Hypercalcemia 2022](https://pubmed.ncbi.nlm.nih.gov/35475520/) |

## Agent Behavior at Critical Values

1. **STOP** — прекратить обычный анализ
2. **ALERT** — показать экстренное сообщение с номером скорой
3. **BLOCK** — не продолжать до подтверждения пациентом что он связался с врачом
4. **LOG** — записать в отчёт что критическое значение было обнаружено
