# Генерация вопросов к защите ВКР

Skill для генерации вопросов разной сложности к защите магистерской ВКР. Содержит только методику формирования вопросов и шаблоны категорий. Персональные данные студентов обрабатываются только в runtime при применении skill'а к конкретным материалам.

## Когда использовать

- Подготовка вопросов к защите ВКР до заседания
- Формирование набора вопросов разной сложности и категорий
- Подготовка вопросов по слабым местам и замечаниям рецензента
- Подготовка вопросов, демонстрирующих внимательное ознакомление с работой

## Когда НЕ использовать

- Для подготовки студента к защите (skill для члена ГЭК)
- Для генерации вопросов без прочтения хотя бы аннотации, введения и заключения

## Протокол

### Шаг 1: Определить ключевые понятия

Прочитать тему, аннотацию, введение и заключение ВКР. Составить списки:
- **Ключевые термины** — специфические понятия работы
- **Методы** — какие методы исследования применялись
- **Результаты** — основные выводы и рекомендации
- **Ограничения** — что автор сам указал как ограничения

### Шаг 2: Базовые вопросы (3-5 штук, сложность 1)

Цель: проверить понимание студентом предмета своего исследования.

| Шаблон | Что проверяет |
|--------|---------------|
| "Что вы понимаете под [ключевой термин]?" | Владение понятийным аппаратом |
| "Какова основная цель вашей работы?" | Понимание собственных целей |
| "Какие ключевые результаты вы получили?" | Знание своих выводов |
| "Как вы определяете [объект исследования]?" | Корректность определений |
| "В чём актуальность вашей темы?" | Понимание контекста |

### Шаг 3: Методологические вопросы (3-5 штук, сложность 2)

Цель: оценить обоснованность выбора методов и глубину понимания.

| Шаблон | Что проверяет |
|--------|---------------|
| "Почему вы выбрали метод X, а не Y?" | Обоснованность выбора |
| "Какие ограничения у выбранного метода?" | Критическое мышление |
| "Как бы изменились результаты при другой выборке?" | Устойчивость результатов |
| "На основании чего вы считаете выборку достаточной?" | Статистическая грамотность |
| "Какие альтернативные методы рассматривались?" | Широта методологического кругозора |

### Шаг 4: Практические вопросы (2-3 штуки, сложность 2)

Цель: оценить понимание практической применимости.

| Шаблон | Что проверяет |
|--------|---------------|
| "Кто может использовать ваши результаты на практике?" | Понимание целевой аудитории |
| "Как внедрить ваши рекомендации в организации?" | Реалистичность рекомендаций |
| "Какой экономический/социальный эффект ожидается?" | Обоснованность ожиданий |
| "Есть ли подтверждение от организации о готовности внедрения?" | Связь с практикой |

### Шаг 5: Критические вопросы (1-2 штуки, сложность 3)

Цель: проверить способность студента к рефлексии и защите своей позиции.

| Шаблон | Что проверяет |
|--------|---------------|
| "Какие допущения вы сделали и насколько они обоснованы?" | Осознанность ограничений |
| "Что бы вы изменили, если бы начали исследование заново?" | Рефлексия |
| "Ваш вывод X противоречит [известному факту/теории]. Как вы это объясняете?" | Устойчивость к критике |
| "Какова главная слабость вашей работы?" | Самокритичность |
| "Вы представляете [CJM TO BE / VSM TO BE / прогноз] как результат. На каких эмпирических данных основана эта оценка и проводилась ли пилотная проверка?" | Разделение проектных оценок и измеренных данных |

### Шаг 6: Смежные вопросы (1-2 штуки, сложность 2-3)

Цель: оценить широту кругозора и связь с другими дисциплинами.

| Шаблон | Что проверяет |
|--------|---------------|
| "Как ваша тема связана с направлением [смежная область]?" | Междисциплинарное мышление |
| "Какие подходы используются в смежных областях для похожих задач?" | Эрудиция |

### Шаг 7: Вопросы для командных проектов

Если ВКР выполнена в команде, добавить 1-2 вопроса:
- "Какой ваш личный вклад в данный результат?"
- "Можете ли вы назвать ключевые показатели для вашей части проекта?"

### Шаг 8: Привязка вопросов к страницам ВКР

Каждый вопрос должен ссылаться на конкретную страницу/раздел:
- Формат: "На странице N (раздел X.Y) вы утверждаете, что... Вопрос: ..."
- Это демонстрирует внимательное прочтение и помогает студенту сориентироваться

## Формат вопроса

Каждый вопрос в итоговом наборе содержит:

```
Вопрос:    [формулировка]
Категория: [базовый / методологический / практический / критический / смежный]
Сложность: [1 — базовый, 2 — продвинутый, 3 — экспертный]
Ожидаемые ключевые слова: [что должно прозвучать в ответе]
Источник:  [из какого раздела/страницы ВКР взят вопрос]
```

## Рекомендуемый порядок вопросов

1. **Базовый** (разогрев) — дать студенту возможность показать знания
2. **Методологический** (основное тело) — проверить глубину понимания
3. **Практический** — связь теории с реальностью
4. **Критический** (финал) — для дифференциации оценки (4 vs 5)
5. **Смежный** — в резерве, если осталось время

Если студент не отвечает на базовый вопрос — не углубляться, перейти к другому базовому. Это сигнал для оценки.

## Рекомендуемый workflow

```
1. document-checker → проверить комплектность
2. dissertation-review → проанализировать ВКР, выявить сильные/слабые стороны
3. question-generator → сгенерировать вопросы на основе анализа
```

## Ограничения по времени

На вопросы отводится **10-15 минут**, реально **4-6 вопросов** с ответами. Рекомендуется:
- Минимум 1 базовый (для разогрева)
- 2-3 методологических или практических (основное тело)
- 1 критический (для дифференциации оценки)
- Держать смежные вопросы в резерве
- Для командных проектов: минимум 1 вопрос о личном вкладе

## Антипаттерны

| Антипаттерн | Почему это проблема | Правильный подход |
|-------------|--------------------|--------------------|
| Все вопросы одной сложности | Не дифференцирует оценку | Микс из 3 уровней сложности |
| Вопросы не по теме ВКР | Нарушение регламента ГЭК | Привязывать к конкретным разделам работы |
| Только "каверзные" вопросы | Не даёт студенту показать знания | Начинать с базовых |
| Нет вопросов по замечаниям рецензента | Упущена возможность проверки | Включить хотя бы 1 вопрос по замечаниям |
| Слишком много вопросов | Выход за тайминг | Максимум 6, с резервом |

## Самопроверка

- [ ] Прочитаны ли тема, аннотация, введение и заключение?
- [ ] Составлен ли список ключевых терминов и методов?
- [ ] Есть ли минимум 1 базовый вопрос?
- [ ] Есть ли минимум 2 методологических вопроса?
- [ ] Есть ли минимум 1 практический вопрос?
- [ ] Есть ли минимум 1 критический вопрос?
- [ ] Каждому вопросу присвоена категория и сложность?
- [ ] Указаны ожидаемые ключевые слова в ответе?
- [ ] Общее количество укладывается в 10-15 минут (4-6 вопросов)?
- [ ] Есть ли вопрос по замечаниям руководителя или рецензента?

## Примеры

**В рамках задачи:**
- "Сгенерируй 5 вопросов разной сложности по данной ВКР"
- "Подготовь 2 критических вопроса по методологии исследования"
- "Какие вопросы задать по замечаниям рецензента?"
- "Сформируй набор вопросов, демонстрирующий внимательное прочтение работы"

**Вне задачи:**
- "Подготовь студента к защите" — skill для члена ГЭК, не для студента
- "Оцени работу" — используй skill `dissertation-review`
