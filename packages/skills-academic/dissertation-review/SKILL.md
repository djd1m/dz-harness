# Рецензирование ВКР (магистерская диссертация)

Skill для подготовки члена ГЭК к защите ВКР. Содержит только критерии оценки и методику анализа из публичного регламента ГЭК. Персональные данные студентов обрабатываются только в runtime при применении skill'а к конкретным материалам.

## Когда использовать

- Подготовка к заседанию ГЭК — предварительный анализ ВКР до защиты
- Оценка текста ВКР по утверждённым критериям
- Формирование краткой справки по работе для члена комиссии
- Сопоставление выводов с замечаниями руководителя и рецензента
- Определение предварительной оценки перед обсуждением на закрытом заседании

## Когда НЕ использовать

- Для написания или редактирования ВКР за студента
- Для подготовки самого студента к защите (skill для члена ГЭК, не для студента)
- Для оценки без прочтения полного текста ВКР

## Протокол

### Шаг 1: Определить формат ВКР

| Формат | Признаки | Акцент оценки |
|--------|---------|---------------|
| **Исследовательский** | Гипотеза, эксперимент, научные результаты | Методология, новизна, корректность выводов |
| **Проектный** | Бизнес-проблема, организация, рекомендации | Анализ среды, обоснованность решений, эффект от внедрения |

### Шаг 2: Оценить по критериям (исследовательский формат)

| Критерий | На что смотреть | Сигналы проблем |
|----------|----------------|-----------------|
| Формулировка проблемы | Чёткая, конкретная, соответствует программе | Расплывчатая тема, нет связи с профилем ОП |
| Структура работы | Логичные разделы, пропорциональность | Главы несоразмерны, отсутствует раздел |
| Логика изложения | Последовательность аргументации | Перескакивание между темами, выводы не следуют из анализа |
| Терминологический аппарат | Определения даны, используются единообразно | Термины без определения, путаница в понятиях |
| Соответствие методов целям | Методы обоснованы, релевантны задачам | Метод выбран без обоснования, не подходит для данных |
| Глубина анализа данных | Достаточный объём данных, корректная обработка | Мало данных, поверхностный анализ, нет статистики |
| Корректность методов | Правильное применение выбранных методов | Ошибки в расчётах, неверная интерпретация |
| Практическая значимость / новизна | Вклад в науку или практику, оригинальность | Компиляция без нового, повтор известных результатов |
| Перспективы исследования | Указаны направления развития | Нет указания на дальнейшие шаги |

### Шаг 3: Оценить по критериям (проектный формат)

| Критерий | На что смотреть | Сигналы проблем |
|----------|----------------|-----------------|
| Анализ бизнес-среды | Глубокий анализ организации, отрасли | Поверхностное описание, нет данных |
| Формулировка проблемы | Чёткая бизнес-проблема в конкретной организации | Абстрактная проблема без привязки к организации |
| Теоретический обзор | Релевантные теории, связь с проблемой | Обзор ради обзора, нет связи с практикой |
| Качество исследования | Достаточность данных, достоверность, методология | Мало респондентов, нерепрезентативная выборка |
| Выводы и рекомендации | Обоснованные, реализуемые, с оценкой эффекта | Общие рекомендации без конкретики и оценки |
| Проектные оценки vs данные | TO BE карты (CJM, VSM) явно отделены от AS IS. Прогнозы не выдаются за измерения | TO BE представлено как эмпирический результат без пилотной проверки |
| Структура и текст | Логика, объём, читабельность, грамматика | Рыхлая структура, опечатки, канцеляризмы |
| Оформление | Соответствие стандартам (ГОСТ, шаблон вуза) | Нет нумерации, неправильные ссылки |

### Шаг 4: Три составляющие оценки

Все три обязательны и **равноценны**:

1. **Текст ВКР** — оценивается по критериям Шагов 2-3
2. **Презентация с докладом** — до 20 минут: структура доклада, визуализация данных, уверенность изложения
3. **Ответы на вопросы** — 10-15 минут: глубина понимания, способность аргументировать, реакция на критику

### Шаг 5: Шкала оценок

| 5-балльная | Словесная | 10-балльная | Описание |
|:---:|---------|:---:|---------|
| 5 | отлично | 8, 9, 10 | Все критерии на высоком уровне, работа выделяется |
| 4 | хорошо | 6, 7 | Большинство критериев на хорошем уровне, есть мелкие замечания |
| 3 | удовлетворительно | 4, 5 | Минимально допустимый уровень, существенные замечания |
| 1, 2 | неудовлетворительно | 1, 2, 3 | Критические недостатки, работа не соответствует требованиям |

### Шаг 6: Изучить отзыв руководителя и рецензию

1. Прочитать **отзыв руководителя** — выделить:
   - Оценку самостоятельности работы
   - Замечания (на которые студент должен ответить в заключительном слове)
   - Рекомендуемую оценку
2. Прочитать **рецензию** — выделить:
   - Замечания рецензента
   - Расхождения с мнением руководителя
   - Рекомендуемую оценку
3. Подготовить вопрос по замечаниям, если студент не ответит на них в заключительном слове

### Шаг 7.5: Сформировать коридор оценок

Обязательный шаг — определить коридор рекомендуемых оценок перед защитой:

1. Взять оценку руководителя (из отзыва)
2. Взять оценку рецензента (из рецензии)
3. Определить собственную предварительную оценку текста (Шаги 2-3)
4. Вычислить коридор: [min, max] из трёх оценок
5. Определить рекомендуемую оценку внутри коридора:
   - Если все три совпадают ± 1 → высокая уверенность
   - Если расхождение 2+ → обсудить на закрытом заседании
6. Указать условия корректировки:
   - Презентация и ответы могут сдвинуть оценку на ±1 балл
   - Неответ на замечания рецензента → минимум −1

**Пример:**
```
Руководитель: 7 (хорошо)   Рецензент: 9 (отлично)   Текст: 7 (хорошо)
Коридор: 7–9   Расхождение: 2 балла → обратить внимание
Рекомендуемая: 4/7 (ближе к оценке текста, расхождение обсудить)
Условие повышения: убедительные ответы о методологии → 4/8
Условие снижения: не ответит на замечания рецензента → 3/6
```

### Шаг 8: Пограничные оценки — guidance

| Ситуация | Рекомендация |
|----------|-------------|
| Сильный текст, слабая презентация | Оценка не выше 4 — все три составляющие равноценны |
| Руководитель ставит "отлично", рецензент "хорошо" | Ориентироваться на собственную оценку, обсудить на закрытом заседании |
| Студент не ответил на замечания рецензента | Снижение минимум на 1 балл от текстовой оценки |
| Хорошая работа, но слабые ответы на вопросы | Максимум "хорошо" — ответы показывают реальное понимание |
| Работа сильная, но оформление плохое | Замечание, но не основание для снижения более чем на 1 балл |
| Мало времени на чтение | Приоритет: введение → заключение → методология → отзыв + рецензия → основная часть |

### Шаг 9: Оценка командных (групповых) проектов

Многие ВКР выполняются в команде. Дополнительно проверить:

| Критерий | Что проверить | Сигналы проблем |
|----------|---------------|-----------------|
| Разграничение вклада | Чётко ли указано что сделал автор, а что команда? | "Мы провели" без уточнения личного вклада |
| Самостоятельность выводов | Выводы основаны на собственных данных? | Ключевые расчёты делегированы коллеге |
| Кросс-ссылки | Корректно ли ссылается на работы коллег? | Нет ссылок или некорректные ссылки |

### Шаг 10: Чеклист финансовой модели (проектный формат)

| Элемент | Типичные ошибки |
|---------|-----------------|
| Конверсии | Завышены без обоснования бенчмарками |
| CAC | Занижен, не учтены скрытые расходы |
| LTV/CAC | > 10 — подозрительно на ранней стадии |
| Ставка дисконтирования | 15% для посевной стадии (реально 25-40%) |
| Сценарный анализ | Только один оптимистичный сценарий |
| Когортный анализ | Средний churn без декомпозиции по когортам |

### Шаг 11: Расхождение оценок руководителя и рецензента

| Расхождение | Интерпретация |
|-------------|---------------|
| 0-1 балл | Нормально |
| 2 балла | Разные приоритеты — обратить внимание |
| 3+ балла | Обсудить на закрытом заседании |

## Рекомендуемый workflow

```
1. document-checker → проверить комплектность пакета
2. dissertation-review → проанализировать содержание ВКР
3. question-generator → подготовить вопросы к защите
```

## Антипаттерны

| Антипаттерн | Почему это проблема | Правильный подход |
|-------------|--------------------|--------------------|
| Оценивать только текст | Три составляющие равноценны | Оценивать текст + презентацию + ответы |
| Не читать отзыв и рецензию | Не знаете замечания, не можете проверить ответы студента | Всегда читать до защиты |
| Задавать вопросы не по теме | Регламент: вопросы связаны с темой ВКР или близко к ней | Формулировать вопросы из содержания работы |
| Перебивать студента | Нарушение регламента (20 минут без прерывания) | Дождаться завершения доклада |
| Ставить оценку до обсуждения | Необъективность, давление на комиссию | Обсуждать на закрытом заседании, голосовать |
| Не фиксировать вопросы | Потеря информации для протокола | Записывать вопросы в черновой лист |
| Принимать TO BE за измеренный результат | Проектная карта (CJM TO BE, VSM TO BE) — это гипотеза, не эмпирика. Выдача прогноза за результат — методологическая ошибка | Проверить: явно ли студент отделяет проектные оценки от измеренных данных? Есть ли пилотная проверка? |

## Самопроверка

- [ ] Определён ли формат ВКР (исследовательский/проектный)?
- [ ] Все ли критерии соответствующего формата проверены?
- [ ] Каждому критерию дана оценка (а не просто "прочитано")?
- [ ] Прочитан ли отзыв руководителя? Выделены ли замечания?
- [ ] Прочитана ли рецензия? Выделены ли замечания?
- [ ] Подготовлены ли 3-5 вопросов к студенту?
- [ ] Справка содержит и сильные, и слабые стороны?
- [ ] Коридор оценок определён (руководитель + рецензент + собственная)?
- [ ] Критерии оценивания заполнены (таблица с баллами 1-10)?
- [ ] Условия повышения и снижения оценки указаны?
- [ ] Расхождение оценок проанализировано?
- [ ] Предварительная оценка обоснована?
- [ ] Оценка учитывает все три составляющие?
- [ ] Вопросы связаны с темой ВКР?

## Примеры

**В рамках задачи:**
- "Проанализируй ВКР по критериям исследовательского формата и сформируй справку"
- "Сопоставь замечания рецензента с выводами работы — есть ли противоречия?"
- "Оцени методологию: обоснован ли выбор метода для данной задачи?"
- "Подготовь предварительную оценку по 10-балльной шкале с обоснованием"

**Вне задачи:**
- "Напиши диссертацию за студента" — skill анализирует, не пишет
- "Помоги студенту подготовиться к защите" — skill для члена ГЭК, не для студента
