# Phase 1: Explore — Глубокое понимание кейса

## Использование
```
/explore-case [путь к директории исследования или текст]
```

## Аргумент
$ARGUMENTS

## Действия

1. **Загрузи скилл:** Прочитай `.claude/skills/explore/SKILL.md`
2. **Прочитай Phase 0** (`00_product_discovery.md`) для контекста
3. **Сфокусируй задачу:**
   - Декомпозиция проблемы (5 Whys)
   - Анализ данных (доступные, недостающие, качество)
   - Карта ограничений (жёсткие, мягкие, скрытые)
   - Success Criteria (бизнес, пользователи, жюри)
   - Ключевой вопрос кейса
4. **Создай файл** `01_case_brief.md`
5. **Покажи Checkpoint 1**
