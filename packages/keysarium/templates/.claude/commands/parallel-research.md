# Параллельные исследования — запуск нескольких кейсов одновременно

## Использование
```
/parallel-research кейс1: [описание] | кейс2: [описание] | кейс3: [описание]
```

## Аргумент
$ARGUMENTS

## Действия

1. **Распарси аргумент** — раздели по `|` на отдельные кейсы
2. **Для каждого кейса:**
   - Определи slug (snake_case, латиница)
   - Создай директорию `researches/<slug>/`
   - Инициализируй README.md

3. **Запусти Agent Swarm** — для каждого кейса параллельный агент:
   - Каждый агент выполняет Phase 0 (Product Discovery)
   - Агенты работают ИЗОЛИРОВАННО в своих директориях
   - Результаты не пересекаются

4. **Синтезируй сводку:**
   ```
   ═══════════════════════════════════════════════════════
   ✅ Параллельные исследования запущены

   | # | Кейс | Директория | Статус Phase 0 |
   |---|------|-----------|----------------|
   | 1 | [название] | researches/slug1/ | ✅ Complete |
   | 2 | [название] | researches/slug2/ | ✅ Complete |
   | 3 | [название] | researches/slug3/ | ✅ Complete |

   Для продолжения каждого исследования:
     /casarium researches/slug1/
     /casarium researches/slug2/
     /casarium researches/slug3/
   ═══════════════════════════════════════════════════════
   ```

## Ограничения
- Рекомендуется не более 3-4 параллельных исследований
- Каждый агент работает в своей директории
- Phase 0 выполняется параллельно, далее — по одному или парами
