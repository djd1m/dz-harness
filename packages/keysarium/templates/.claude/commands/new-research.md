# Новое исследование

Создать новый изолированный проект исследования для параллельной работы.

## Использование
```
/new-research [название кейса или тема]
```

## Аргумент
$ARGUMENTS

## Действия

1. **Определи идентификатор** — создай slug из названия (snake_case, латиница)
   - Пример: "Автоматизация КЦ для банка" → `bank_kc_automation`

2. **Создай директорию** `researches/<slug>/` со структурой:
   ```
   researches/<slug>/
   ├── prototype/
   ├── diagrams/
   └── README.md
   ```

3. **Создай README.md** с метаданными:
   ```markdown
   # Исследование: [Название]

   **Создано:** [дата]
   **Статус:** 🟡 В работе
   **Домен:** [определить]
   **Тайминг:** [если указан]

   ## Артефакты
   - [ ] Phase 0: Product Discovery
   - [ ] Phase 1: Case Brief
   - [ ] Phase 2: Research Findings
   - [ ] Phase 2.5: CJM Prototype ⭐
   - [ ] Phase 3: Solution Strategy
   - [ ] Phase 4: Architecture
   - [ ] Phase 5: Presentation
   - [ ] Phase 6: Packaging

   ## Описание кейса
   [Текст кейса]
   ```

4. **Выведи подтверждение:**
   ```
   ═══════════════════════════════════════════════════════
   ✅ Исследование создано: researches/<slug>/

   Для запуска полного пайплайна:
     /casarium [текст кейса]

   Для запуска отдельных фаз:
     /discovery, /explore-case, /research, /cjm-prototype,
     /solve, /architecture-phase, /presentation

   Все артефакты будут сохранены в researches/<slug>/
   ═══════════════════════════════════════════════════════
   ```

## Параллельные исследования

Каждое исследование полностью изолировано в своей директории. Можно запускать несколько `/casarium` для разных кейсов, каждый в своей `researches/<slug>/` папке.

Список активных исследований: `ls researches/`
