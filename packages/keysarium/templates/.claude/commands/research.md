# Phase 2: Research — Бенчмарки, аналоги, технологии

## Использование
```
/research [путь к директории исследования или тема]
```

## Аргумент
$ARGUMENTS

## Действия

1. **Загрузи скилл:** Прочитай `.claude/skills/goap-research-ed25519/SKILL.md`
2. **Прочитай Phase 0-1** для контекста
3. **Режим: PARANOID** — ноль непроверенных утверждений

4. **Исследуй по направлениям:**
   - Аналоги — кто решал похожую задачу
   - Технологии — модели, фреймворки
   - Метрики — результаты у аналогов
   - Регуляторика — требования в домене
   - Anti-patterns — что НЕ работает

5. **Создай файл** `02_research_findings.md`
6. **Покажи Checkpoint 2**

## Параллелизация (Agent Swarm)
Запусти 3 агента параллельно:
- Agent 1: Аналоги + метрики (benchmark solutions)
- Agent 2: Технологии + Anti-patterns
- Agent 3: Регуляторика + market data
Синтезируй в единый `02_research_findings.md`.
