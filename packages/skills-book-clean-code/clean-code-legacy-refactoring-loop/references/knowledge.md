Проблема: Нужно выбрать реакцию на падающую скорость изменений в запутанной кодовой базе.

## clean-code-ch12-p204-ku06 — Оставляйте общий каркас шаблонному методу

Проблема: Надо сохранить единый алгоритм, когда специализированные версии различаются одним шагом.

Содержание: В базовом классе удерживайте неизменную последовательность, а различающийся шаг сделайте абстрактным и реализуйте в подклассах. В примере отпусков общий метод считает базовые часы, применяет минимум и начисляет результат, а подклассы задают только юридическую корректировку. Это ШАБЛОННЫЙ МЕТОД для устранения высокоуровневого повтора.

Применимость: Используйте, когда варианты процесса имеют общий порядок и отличаются ограниченным специализированным действием.

Ограничения: На процитированных страницах отдельная граница применимости паттерна не сформулирована; показан случай двух вариантов с общим алгоритмом и одним различающимся шагом.
