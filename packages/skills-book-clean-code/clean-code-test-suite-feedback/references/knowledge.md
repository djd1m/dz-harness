## clean-code-ch09-p153-ku02 — Три закона короткого цикла теста и кода

Тип: methodology

Проблема: Как вести цикл разработки от отказного теста к рабочему коду.

Содержание: Не пишите продуктовый код до отказного теста; тест пишите лишь до момента отказа, а продуктовый код — лишь до прохождения текущего теста. Тест и продуктовый код создаются вместе, тест немного опережает код.

Применимость: При разработке малых инкрементов поведения.

Ограничения: Правила ограничивают объём следующего шага текущим отказным тестом.

Ограничения: Средства покрытия предназначены для обнаружения пробелов стратегии и непроверенных ветвей if или catch.
